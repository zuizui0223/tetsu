# v374 全球2,048実鉄道路線点におけるWorldClimの直接比較と100/200km格子の解像度バイアス（解析前固定）

2026-11-24。v373で全世界GERS通常鉄道2,237,043.481kmの100km等面積格子×WorldClimに温帯偏在が見えた。しかし、鉄道線分を`100km cell centre land/temperature`で代表させたため、山間・海岸・島嶼・勾配が厳しい場所で局所線路の温度誤割当がありうる。本v374は**先に鉄道や植物の温度結果を見ずに無作為抽出して検証済みの全球rail-km位置2,048点**で、線路上の実WGS84標本点と格子中心を比較する**源データ空間解像度QA**である。植物への適応・列車種子散布の検定ではない。

## 固定アウトカム
1. 2048元抽出番号0:2047の完全性、元標本が各sourceクラス標準/狭軌/不明、旗、ソースgeometryフラグが正しいことを監査。元自然陸地の分類が曖昧・WorldClim nodataの場合はNAとして**2048を減らして新点を再抽出しない**。
2. 各線路中心点の**WorldClim BIO1℃**を直接サンプルし、大陸と固定温度帯`cool <8℃`、`temperate 8–<20℃`、`warm >=20℃`を記録。ただし個別座標や元原線分SHAは公開成果物には出さない。
3. 元同線路位置を元100km・200km等面積格子へ対応させ、**同一格子の中心点**の土地分類とWorldClim気温・温度帯を計算。同一元抽出位置で`real railway point BIO1 - center BIO1`の平均・分位差、気温帯不一致割合、島/海岸で格子中心が陸でない割合を測る。
4. 6大陸それぞれ源点数、気候データ有効点数、平均・10/50/90％数値、固定帯別出現数/割合、元bridge/tunnel flagの割合を示す。全球線路長の真の気温帯構成を**線路kmに比例する無作為抽出の頻度**で推定する。ただし鉄道モデル源重複/複線の空間相関があるため通常二項信頼区間を生態的独立観測CIと呼ばない。各continentの標本数が20未満なら定量比較は候補だけ。
5. v373の100km格子元railkm温度帯share（BIO1付帯付き2,146,220km=95.94%）との**記述的比較**を行い、大幅に異なる場合は従来v373粗格子の生態効果への直接転用を停止。線路中心点の実大陸またはmacroclimate温度は植物種固有の温度選好や微気候を示さない。
6. 植物2025年iNaturalist約13.7GB全球v369データは**本解析に投入しない**。これを植物マクロの実績に水増ししない。v369完走後にv371で元全球plant richness/Jaccardを同100/200km実GERS railway kmに突き合わせ、記録努力・気候・緯度を調整して全大陸保留予測を行う。

成果はソース入力SHA/項目数/大陸別・温度帯別件数・格子精度診断だけを保存。抽出源鉄道点WGS84、原GIS UUID、レア植物位置、種×出現レコードは発行しない。
