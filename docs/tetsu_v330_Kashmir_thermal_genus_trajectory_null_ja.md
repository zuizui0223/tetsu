# v330：カシミール2014〜17年の暖地性種の新規記録は分類群形質帰無を超えるか

## 検定の意義

v329の2014→2017年温度EIVE中心値の変化（「記録消失による項＋新規記録による項」）は、種集合の加法的な*算術分解*だけである。新規記録による内陸Plot2の暖地性への寄与が、**もともとの種出現記録を完全に固定した形質帰無**よりも大きいかを調べた。

### 帰無の固定条件・限界

- 31地点×2014・2017年×Track・Interior Plot2の元観測種集合、記録の出現/消失/残存判定、サイトの駅/駅間、EIVEに対応できたか、源種数は**すべて固定**。
- 2014/17年に両生息地で1種以上の*残存*EIVE分類群を持つ、**同じ23野外地点**を比較。厳格化は各年の各群集でEIVE>=3体系、**数値のある種3以上、残存種1以上**の同じ13地点。
- 生物のEIVE温度中心値を**すべての対象種に対して同じ対応表で一斉にシャッフル**（全種間1999回）。これにより、同一種が複数元source区画で持つ形質は一回の置換内で変わらず、出現頻度・生物群集・野外の空間構造が維持される。**ただし属や系統の形質依存性は壊す**ので、無条件に許容できる生態的帰無と主張しない。
- 別帰無は同じ元source**属内**で形質値を交換。対象90源分類群のうち属内複数種を持つのは**9属・21種**だけで、69種は固定される。属内帰無で不支持でも属内選別が「存在しない」ことの証明ではない。
- 形質ラベル帰無は**野外の無作為な環境処理ではない**。事前のv329結果を見て導入した探索的診断、多重比較補正なし。完全な動態・生理学的な温度効果は未識別。

全種間シャッフルでは、新規記録寄与差は技術帰無上側の少数例に位置した。しかし**全体の温度中心値差は対応する同帰無で顕著ではない**。属内だけでのシャッフルでは、もとの新規記録寄与差0.414は帰無範囲に含まれた。

厳密には、**EIVE温度形質と元のsource種名・属の構成が対応していること**が、新規記録種の温度上積みの部分を説明できるというパターンである。欧州EIVEがどのような分類群に高い温度値を付与するか／元の内陸種プール自体が暖地性寄りかを独立に統制しない限り、「列車から内陸へ暖地種が移動した」と結論できない。

## より一般生態学的な仮説と現時点の残る壁

**観察された事実として**、カシミールではTrackの温度中心上昇は相対的冷涼性種の記録消失という項が主で、遠い内陸Plot2では暖地性種の新規記録という項が主。見かけの方向が同じ「暖地性への変化」でも**分類群の入替で生じる経路が異なる**。欧州のスロベニア鉄道内では中心差が属間成分に集中したv322と、分類階層に関する同じ視点で次を検証できる。

ただし、カシミールでの因果的な到着・生存・消失の区別、強い気候勾配（原著は標高1591–1741mの一河谷）、完全に非影響の内陸対照、種の温度生理の独立実測、時間的検出確率の標準化は未解決。これらが揃うまでは、「鉄道が気候制約を解除する」という主張は採用しない。
