# v335 凍結：駅間温度選好の出現種等重み→原著数値重みの符号反転は特定の極端値か

2026-11-23。v334の本物の源plot数値再解析で2014年の地理標高対応14組（G1）について`presence Δ=+0.288560`、`sqrt(source) Δ=+0.130675`、`source direct weight Δ=-0.037710`という**事後に発見した計量方法に依存する反転**があった。原データsource正値2941件・中央値1・最大103.6、100超1件。これは探索的フォローアップ、事前確証研究ではない。

## 追加する判定を結果確認前に固定
- 元Dryad XLSX（SHA256 `529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474`）と独立EIVE SM08（MD5 `0f0ce19cd2a781eeed027d8b0acadbcb`）を真正検証し、source·presence index照合v334と**同じ**地点/ゾーン・分類群ゲート、G1/G3ペアを固定。元数値の単位を勝手に百分率や種子量と呼ばない。
- 重み`(min(source positive value, cap))^alpha`、各元野外区画内で規格化。cap無しでalpha=0,0.25,0.5,0.75,1、原数値重みalpha1でcap=100,20,10,5を固定し、source最大103.6の影響を評価する。alpha0は元の出現種等重み、alpha0.5はv334平方根、alpha1 cap無しはv334原数値重みと数値一致しなければ停止。
- 元sourceの100を超える陽性species-cellが対象ペアのBT、BI、ST、SIどの群集クラスに入るかの**匿名件数**を報告。種名・元地点・原座標・生データは再配布しない。区画ごとの単位が不明な数字の切り上げ・下げを生物学的な植生除去処置と解釈しない。
- **1種ずつ**原著数値重みで外し、地理マッチを一切変えずCWM再計算。元の全対応ペアが維持できた削除での最小〜最大効果、方向を変える削除数、主要な寄与種（最大5）を記録。1種を消してペア数が減る場合は主結果と混同しない。
- 主要パネル：2014年G1 relaxed 14、2014年G1 strict 5、2014年G3 relaxed 7、2017年G1 EIVE3体系>=1種の薄い12。非無作為の駅・駅間、外部鉄道以外の対照なし、少数種のsource coverスコアの意味不明のため、因果機構・生物量・温度微気候を結論しない。
- 仮に単一極端値を除いても効果が符号反転する場合は、**「出現種構成に対する温度選別」と「元source数値で表す優占構造」の分離**という一般群集集合仮説の候補になる。原調査のcoverスケールの妥当性と他の研究での再現がなければ普遍性主張はしない。
