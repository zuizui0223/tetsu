### Data, metrics and strict stops
- Official iNaturalist 2025 public API, `taxon_id=47126` Plantae, `quality_grade=research`, `captive=false`, `geo=true`, 2025-01-01 through 2025-12-31, `per_page=1`. Per original finite land cell, take **WGS84 bbox enclosing its EPSG:6933 100km square**. Only read `total_results`, HTTP status and response schema/hashes, NOT individual source records, species names, observer/GPS/photo identities. The rectangle is larger than the original projected cell, so all count results are explicitly tagged **source rectangular bbox opportunity**, NEVER equal-area cell census or rail proximity observations.
- Source calls 1/sec or slower and bounded retries on HTTP429/5xx, never spam. On source failure, count is NA, **not 0**. On valid API zero records, report `0 detected research-grade public plant observations`, NOT absence of plants or species/rail habitat.
- Every original source cell remains in denominator, including cool remote land and warm isolated areas. Report source count and `>10k` bulk-API threshold (counts only, not full original occurrence). Publish continent×climate-band 18 strata with n source windows, source total/median/min/max, number no observed records, number unavailable, number with >=100 records etc, preserving finite original sampling inclusion pi.
- This is an **observational sampling-effort audit**, not a thermal niche analysis and not a claim of railway flora. It quantifies whether prior seven-paper/urban volunteer data could ever form a worldwide independent matched rail/nonrail vegetation community dataset. Posterior use of high-effort windows must not substitute for preselected global geographic sample.
