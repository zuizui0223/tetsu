## 偽鉄道網をどのように作ったか

- v371正規化Ridge λ0.10の大陸丸ごと留保＋1,000km地理block単位の等重み予測を再現。同じ元2025年景観植物記録種数、隣接格子Jaccard、元観測者数、観測件数、WorldClim温度・絶対緯度、元資料・源空間格子は固定。写真観測の位置を線路へ寄せたわけではない。
- `continent × 年平均気温の帯域 <8 / 8〜<20 / >=20℃ × 絶対緯度10°`ごとの元EIVEではない**鉄道GIS kmの観測値集合（真0 kmを含む）**を、対象の**観測努力が確保された陸地元格子間**だけでシャッフルした。元GIS線路形状そのものを現実的な建設制約の下で再配置したものではない。39回、seed `tetsu-v375-20261124-conditional-rail-map-placebo`、温度/緯度/大陸全体のrail km分布を保持。
- 100kmの植物記録・気候・陸地条件通過格子3,455、隣接Jaccard対応4,736、偽地図のsource railkm再配置可能格子約3,441（各回3,098〜3,146格子が元の値と異なる）。200kmは1,442格子・隣接1,953、再配置可能1,429格子。各大陸留保予測におけるM0−M1のMSE差を6大陸等重み平均。帰無39回は狭い尾分率の推定には不向き、値は**探索的な技術診断**。

## 最重要な未識別の交絡と次の原sourceゲート

1. **鉄道網の場所と都市化・道路・居住人口・土地利用**は強く共起する。本帰無はcontinent/BIO1/緯度を保持するが、鉄道建設地の都市中心性・道路網・人為植物栽培・iNat撮影可能場所の共起を保持しない。そのため、残る予測上積みは鉄道因果効果でなく**他の人為的インフラや都市景観のproxy**で説明される可能性がある。次段で同一100km/200km全球格子の独立元GHSL Built-upや道路網kmを実ソース追加して**M0＋都市化/道路 → M1＋都市化/道路＋鉄道km**を大陸外予測する。
2. **観測対象は地域/景観全体の元iNaturalist公開写真記録植物相**。元植物のgeoprivacy_obscuredの明示フィールドはオリジナル公開open TSVに無いため、個別植物が80m以内の現役鉄道敷地にいたと判定していない。調査努力は元観測数・観測者数のみ調整、検出率や花が目立つ特性・撮影アクセスの偏りは未解決。
3. 気温は1970–2000 WorldClim BIO1であり、元2025植物の種固有の温度選好・耐熱性ではない。鉄道GISは2026元sourceで、列車運行・貨物・直接種子散布の測定はない。
4. 植物の機能的類似性H2はADEPT元59,369植物種候補traitと全球iNat taxonomy crosswalkが未確認。全球暖地性H3は独立全球species T原ファイルの真正取得未完了。**現在の全球肯定結果は記録種数の予測増分・100km Jaccard予測増分まで**である。
5. 次の原ソース照合で都市化・道路が追加され予測増分が消えたなら、因果結論を強めず、**本GIS源はhuman accessibility proxy**とみなす。追加後も残れば、実標準植生plotでの鉄道/非鉄道対照を使い、確証的な物理種子散布/定着の検定へ進める。
