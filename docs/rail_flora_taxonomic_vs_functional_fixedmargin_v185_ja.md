## 検証した問いとサンプル単位

地域種プールからの人工生息地収束研究に先立ち、**鉄道駅内の群集の分類学的類似性と生活形構成比の類似性が、同一の種数・元分類群の占有駅数制約下で予測できるか**を見る。都市間または国間の105駅ペアは重複する15元駅から計算され、**独立n=105のフィールド実験ではない**。同一原著の国境を跨ぐ15駅は、独立の研究としてn=1。

- 分類学的類似性：種出現のJaccard `|Si∩Sj|/|Si∪Sj|` を105ペアで平均。
- 機能構成の類似性：5つのRaunkiaer生活形について、相対分類群数ベクトルの `sum_g min(p_ig,p_jg)` を105ペアで平均。分類群Jaccardとは指標定義が異なり**生の値を直接大小比較しない**。
- NULL A：鉄道元原著由来の全359分類群の出現率と各駅の種数を固定し、15駅間で2×2スワップ。
- NULL B（優先解釈）：元著者の気候区分TWS/TSS/MED内でのみスワップ。さらに各気候群内の**分類群の出現頻度**を固定。原著の地域差・標本面積・サンプリング季節・管理歴を操作した実験ではない。
- どちらも2チェーン×120 draw、burnin 18,000 swap提案／chain、独立draw間1,800提案。交換で元サイト種数と元種頻度が保持されることを逐次確認した。統計的p値・MCMC混合保証はない。

原著3気候群の**同気候間39駅ペア**でも、生活形重複は観測0.8928405に対し気候内NULL0.9298123（差 **−0.0369718**）。気候が異なる66ペアでは観測0.8674712／NULL0.8869105（差 **−0.0194393**）。**同気候群での生活形異質性**が残るので、「気候区分が違うから生活形が違う」だけで説明するモデルは不十分という探索的所見。一方Jaccard同気候0.3014731／NULL0.3014507（差+0.0000225）、異気候0.2646548／NULL0.2659077（差−0.0012529）はいずれも小さい。

## 解釈の境界

1. これは**すべて鉄道原著内部の分類群から作った内部種プールの帰無**である。鉄道以外の独立した周辺自然植生、地域種プール、道路並走対照と比べていない。従って「鉄道が生物地理を上書きした」「鉄道特異的環境選択を確認」「全球で機能分化」とは断定できない。
2. 5生活形しかない粗いカテゴリ。機能距離は分類群名を見ずに組成比重複を測るため、単一種の頻度条件では期待の構造が異なる。機能の異質性の原因は形質環境フィルターのほか、局所管理、サンプリング面積200–800m²、季節（南部4駅は夏秋のみ）、希少種や局所史が候補。
3. 両帰無のMCMC 240技術標本と全105駅ペアは生物学的独立標本としての数ではない。独立原著数は1。帰無の端尾分位位置は探索的で、正式なp値ではない。
4. 18.3で確認済みの原表と本文の不一致（Canna indica station12 vs printed53%、rare singleton99 vs prose100）は原著側の齟齬として保持し、数字を有利に直さない。
5. 今後の全球/大陸スケール課題は、同じ地点粒度に基づく独立の**地域自然植生の種プール**を取得し、原著単位・生息地タイプ・気候・面積・努力・種名正規化を統制した鉄道vs非鉄道の予測を行うこと。本資料だけでは案1の核心（地域プールより鉄道が似るか）は未検定。
