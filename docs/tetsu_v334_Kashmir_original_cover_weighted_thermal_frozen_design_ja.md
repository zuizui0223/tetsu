# v334凍結：カシミール駅間の暖地性選好は「出現種数」だけでなく「優占度」にも現れるか

2026-11-23、v333結果を見た**事後探索的追加解析**。元sourceはRashid et al. (2021)の真正Dryad `Matrix_plot.xlsx` version99735 SHA256 `529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474`。EIVE原温度中心はZenodo 7534792、SM08 MD5 `0f0ce19cd2a781eeed027d8b0acadbcb`。

## 基本設計
- 原本species×site-year-zoneの数値表には0（sourceで不在）、正の数値（原著の記録被度などのsource数値単位）、4つの真の欠測セルがある。原著本文で単位を改めて確認しない限り、この値を無条件に%被度・本数・バイオマスと呼ばない。実際にどのような数値分布か、最大値・最小値・異常値・陽性種数のみ監査する。
- 31地点×2014/2017×4区画の全original非欠損植物セルで `source value > 0` の種index集合がv254の真正出現集合と一致することを検証し、不一致なら解析停止。欠測4セルは推定/0置換せず該当plotそのものを計算対象外。
- v332で地理・元source標高・形質被覆によって選定した**同じ駅間/駅の1対1ペアを固定**。主候補：2014年EIVE >=1体系、3種以上/30%、G1（15km/75m、14組）。感度：2014年厳格EIVE>=3・5種/50%のG1（5組）、2014年緩いG3（種数被覆まで調整7組）、2017年EIVE>=3・1種以上G1（12組）。
- 同じオリジナル種名セット（形質既知）で、群集温度中心値を①**出現した形質既知種すべてに等重み**、②source正数値をそのまま正の重みとしたCWM、③**sqrt(source正数値)**を重みとしたCWMで比較。各区画のsource重みは1へ正規化。②はsource数値の信頼性に依存、③は極端な優占種影響の探索的感度。
- 元v332の①の温度結果と数値が完全一致しなければ停止。元source G1マッチ対象を形質値やsource coverで選び直さない。
- 駅間−駅の`Track−Interior2`相対EIVE中心差について、各重み方式のペア平均、ペア符号数、Trackのみの駅間−駅差とInterior2のみの駅間−駅差を提示。各plotで元source陽性値の最大1種が総源量に占める割合、形質既知種の相対重みからの有効種数 `1/sum(p²)` を監査。
- 数値の違いだけで「選択圧が個体群優占量に作用した」とは結論しない。群集種数・被度・開放性・調査者・生物量の真の意味を確認し、観測されたsource重みは現地での各種の出現程度を示す参考指標とする。駅/駅間は無作為割付でなく1本の鉄道回廊。列車散布、温度センサー、植物の生理的限界は非観測。
