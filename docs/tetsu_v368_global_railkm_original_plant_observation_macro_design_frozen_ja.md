# v368–v371：全球鉄道網を母集団とする植物・形質・暖地性マクロ解析（2026-11-24事前固定）

## 新しい全体方針
過去のスロベニア89サイト、チェコ35駅、スロバキア19駅は既存データの**技術的QA・外部妥当性の参考**に留め、主解析の地域サンプルとして使用しない。真の対象は**世界の全線路に沿って抽出された観測区**。既存v357真正全128原本から2,054,855 Overture railway-typeセグメント・約289.22万km、v361通常鉄道地図上稼働候補1,536,226 GERS線分・約223.70万km、GERS connector physical graph3,547,570ノード、44,710成分を原本全量・ハッシュで確認済み。

**強い仮説**：実際の物理鉄道網は、局所植物の種同一性を均質化しなくても、フィルターされた**機能組成**（生活形・散布様式・一年生率）を均質化し、地理的・気候的な境界を横断する。別に**microclimate暖地化**（沿線が周辺気候に比べて温暖地性種を持つ）を評価。ただしspecies T独立sourceが必要で、単なる地元WorldClim BIO1とは違う。これらは元sourceと検証フローのゴールであって、肯定結果ではない。

## 全球original first-stage rail-km母集団
- 元source Overture Maps 2026-11-18.0、[v357原本全128/128・16個source-checksummed rail-only Parquet artifact #45342573085](https://github.com/zuizui0223/tetsu/actions/runs/45342573085)。公式raw transportation 354,631,439 records→rail2,054,855、原全rail geodesic2,892,198.162km、ODbL。
- **通常鉄道のprimary sampling frame**: source `subtype=rail`, `class in {standard_gauge,narrow_gauge,unknown}`, `is_abandoned/is_disused/is_under_construction`を除く。Tunnel/bridgeは交通網原本としては残すが、植物調査対象となるground-level trackbedか否かの区別を別属性で保存する。unknownはactual train operationを保証しない。形質効果の地図上frameと実運行線を混同しない。
- **母集団内の本当の線路長から、全球ランダムに独立点を抽出**。Source rail-only全16 Parquetをソートして読み、（1）全該当原線分のWGS84楕円体測地線長Lを全件足して母集団線路長を固定し、（2）固定seed `tetsu-v368-20261124-rail-km-global-random-seed`により[0,total_L)から**2048個の一様独立乱数ターゲット**を抽出する。各累積ターゲットが属する実ソース線分上で、WGS84 geodetic `at = (target - cumulative_before)/segment_length`位置を実geom verticesに沿って補間。これは世界の元source normal candidate **線路中心線の長さに比例した、exact with-replacement rail-km sampling**。独立した軌道中心線1点が仮説の生態学的replicateではなく、二重線や並走複線のGISモデルで同じ生息地が重複し得る。各fixed pointのsource GERS UUID/lineshape/GPSはGitHubへ発行せず、100km landcell等の安全なaggregated geo regionだけ発行。ローカルCI artifactには必要最小限のsite WGS84 point座標を持ち、original user rare plant GPSとは別物であると注記。
- **全球サンプルを見て都合のよい都市や国へ置換しない**。Original 2048 railkm points sample all rail network including high-/low-iNat-effort and rail sites with zero observed plants. Source errors/missing source strataはゼロflora扱いせずNA。Source 16 rail-only Parquet sourceSHA・全source normal candidate n・kmは先行v361 original aggregateと数値照合。Rail flag source bridges/tunnels、name primary、class、connected components未付与の限界を個別に監査する。Original source random station point attr GPS is sampled **track centreline, not actual observed plants**. Same source segment can be selected more than once with independent fractional position (with-replacement); must not dedupe these, otherwise rail-length sampling design broken.

## 全球original botanical source
- **Global independent public observation snapshot candidate**: iNaturalist Open Dataset AWS `s3://inaturalist-open-data/observations.csv.gz` and `taxa.csv.gz`, compressed TSV with source `observation_uuid,observer_id,latitude,longitude,positional_accuracy,taxon_id,quality_grade,observed_on,anomaly_score`; source taxonomy `taxon_id,ancestry,rank,name,active` includes phylogenetic rank and Plantae ancestry. Metadata is **monthly, photo-linked, not every global vegetation plot**. Snapshot original Content-Length, Last-Modified, ETag/SHA256 must be pinned at download/run. No raw site×taxon or source observer IDs disseminated.
- CRITICAL **geoprivacy**: iNat open metadata CSV does **not include coordinates_obscured, geoprivacy, or taxon_geoprivacy**. Therefore small-radius nearest railway vs control inference is NOT valid on metadata alone. Before classifying original observations within 80m rail or plants in nearby controls, independently validate public source privacy state using iNaturalist official API observation ID (or GBIF open occurrence where original country/gps uncertainty and geoprivacy flags are known). Obscured source coords random 0.2° rectangle must be excluded from fine-scale grouping. Original taxon ID is not equal independent thermal niche trait.
- The source observations are a volunteer photo-based convenience sample and source `quality_grade` is site/species QC, not standardized floristic absence or area coverage. **No positive global convergence conclusion solely from presence observations without matched source effort and habitat controls.**

## Four linked worldwide ecological tests (one consistent probabilistic rail-km sample, outcome sources auditable)
**H1 Taxonomic turnover vs rail geography/network**: globally probability sampled rail-km segments with true GERS physical components, associate original geoprivacy-valid species point observations in fixed 1km radius/5–10km span window; calculate effective standardized source richness/occupancy and pairwise Jaccard/Sørensen in geographically/bioclimatically matched windows, rank independent global rail-clusters as unit. Compare decline with straight distance and matched nearby road/nonrail pseudo-corridors, not generic across-continent pairs with 0 shared taxa. Connectivity shortest-path to be computed for **physically connected nearby sites**, not assume giant component is one train-operated route. Random "same GERS graph component" is not a named line.
**H2 Functional convergence**: compare original source community-weighted plant life form / growth duration / dispersal guild and, if available, seed mass vs height trait-vectors under **same globally harmonized trait ontology**. Original Pladias + Slovenia author-defined traits are European subset and do not supply globally complete 2048-rail-point guild coverage. Need independent global trait source coverage report, missingness not impute "other" and leave-one-continent-out plus regional study random effects. Cross-taxon structural patterns must surpass source species frequency / local climate conditioned null. Test functionally homogeneous but taxonomically different rail windows: `Δfunctional_similarity_rail-minus-control >0` while `Δtaxonomic_similarity≈0`. This can falsify independently.
**H3 Warm-biome species thermal bias**: Independent global native species climate envelope preferred temperature (e.g., original source 2022 Harris global plant species tmean entire EIDC data, only after full source reliable download and taxonomic crosswalk), independent 2015–2022 plant range source vs rail 2025 observations. Define site species thermal affinity, compare matched within-local species pool rail vs control in same climate/grid and effort; adjust same whole region background, climate and detection. WorldClim SITE BIO1 is a covariate, NEVER a species niche outcome. C4 fraction cannot be computed globally without independent source species functional C4 trait; if unavailable report missing source.
**H4 Establishment gate vs connectivity**: Stratify by WorldClim macroclimate and open habitat vs urbanization, rail flag surface/bridge/tunnel, observer effort & original 2025 surveys. Test heterogeneity of source rail-vs-control and effective rail network distance; use blocked leave-one-continent-out/biome-out not just within-country random pairs. Not a train traffic mechanism until independent freight/schedule/actual diaspores measured. Branch/trunk **functional categories** cannot be fabricated from Overture class; require third-party route hierarchy/service.
