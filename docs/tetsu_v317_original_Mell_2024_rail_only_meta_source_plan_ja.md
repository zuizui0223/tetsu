# v317 解析前固定：Mell et al. (2024) の真正補足データから「鉄道だけ」の比較可能性を監査する

2026-11-22 JST。v316の1回廊での気候仮説が非支持であることを確認した後、独立地域の原野外対照を補うための外部メタ原資料監査。**効果値を再解析する前の設計**。Mell et al. (2024), Environmental Evidence 13:4, DOI 10.1186/s13750-024-00328-3、systematic review の公開[Additional file 8](https://link.springer.com/article/10.1186/s13750-024-00328-3) を原著の公式Supplementary.xlsxから取得する。追加で[Additional file 5](https://link.springer.com/article/10.1186/s13750-024-00328-3) の元研究ID・方法・バイアス評価情報を照合できれば比較する。原論文は47原著から205効果量で**鉄道は全比較の約1%**と報告する。

## 修正不能な研究単位とメタ分析の設計
- 当初の関心は「鉄道盛土とそれに似た非鉄道群集で維管束植物の種数・被度・バイオマスが異なるか」。ここでの **railway verge** は**鉄道敷（バラスト肩、盛土等）のうち原著が定義したverg​​e**であり、線路の車両運行強度や直接列車運搬とは違う。原著メタ比較の対象外の線路上・駅内のデータは、近似で入れない。
- 元レビューのQ2「自然の参照生息地とvergeを比較」の原204～205例だけをsource verification する。原著の**原論文ID**で数え、効果量の行を独立研究と数えない。効果の方向は元公開シートにある処置/対照定義を原文で検算する。区画や生物種分類が別の効果を同じ研究内で反復する場合は論文単位クラスターとして保守的に扱う。
- 効果量の種類（植物の種数 vs abundance/biomass、外来 vs native vs 全植物）を統合して一効果にはしない。元論文が計算した種数・バイオマスなどの標準化効果（d等）と分散を、**元XLSXの列名・方向が原著に明記された場合だけ使用**。標準化比較と生態学的種共有・温度指標を混同しない。
- 原著XLSXの全ワークシート名、行数・列数・ヘッダ先頭20列、元railwayレコードの生文字、railway/road/powerline/pipeline/waterway分類件数、元published case count 205との一致を検証。原著の空欄セル/重複・研究IDは明示的に保持。元のメタ集計にrailが1–2効果量しかないなら**研究間統合・予測区間・年・気候交互作用を行わない**。
- 元効果量について、標本分散が取得され、独立著者研究が少なくとも**5**件あれば、研究IDごとに動作の再現確認を行い効果を展示する。主「独立研究での普遍性」claimには少なくとも**10**独立論文と事前固定の参照整合性を要求。**5件未満では証拠マップと個別効果量のみ**。
- 道路等は**鉄道以外の比較用負の対照**として分布・方向の内訳だけ表示し、道路研究が多いからといって鉄道へ効果を借りない。
- 今回の「温暖気候ほど鉄道で温暖種」というv315/v316仮説Aは、種の温度親和性のsite-matched比較＋共通気候が必要であり、meta Excelの植物richnessを温度指標として使わない。

## 外部の独立matched raw候補
2026年李 Weitao, 鄭 Yulong & van Kleunen, J Environ Manage 413:130380, DOI 10.1016/j.jenvman.2026.130380 は14駅84個の鉄道/隣接未撹乱区画を同年（2022年11月）調査、熱帯〜温帯の緯度勾配と土壌水分・窒素/リン・外来植物種数・植物被度・バイオマスを報告。これらは以前v315時に発見した候補であり新発見として再カウントしない。CrossrefはFigshare共有リンク `https://figshare.com/s/0a7d857ba7c0a746ba4b`を返すが、原区画×植物種・微環境データは確認できない（当時403）。新しい鉄道補足メタの原著研究が代用となるわけではない。

## 検証・停止
原XLSXは出版社公式URLからCIランナーで取得して**原ハッシュ/ZIP部材・行列寸法**を確定し、原本XLSXは一時使用のみでリポへコミット・再配布しない。正式データとして確定する前にsource_original office workbookの表構造を解決し、原論文の225本?ではなく**205 cases**、47 studiesの記述と検算する。source rail codingが0–2 caseのみならメタ推定値をでっち上げず研究デザイン・原データ取得の不足を結果として数える。国ごと多重化・交通ODなど観測されていないものは導入しない。

**期待するアウトカム**：original published raw meta Excel（行の元効果量、元分散、元論文ID）から、実際に独立した鉄道近接対照が何件含まれるかを明らかにし、既存の欧州比較を推論的metaと呼べる条件／呼べない条件を資料で確定。新しい自然実験の因果効果は請求しない。
