# 欧州外鉄道で草丈構成の傾向は再現するか

2026-11-20。カシミール以外の原資料を探索し、西オーストラリアの鉄道用地で同面積解析、欧州との同一定義の形質比較、北京・パース付表の支持域監査まで実行した。

**今回追加した資料から、欧州外でも頑丈に残る負の草丈―標高関係は確認できなかった。世界中で関係がないことを示したわけではない。**

| 検証 | 結果 |
|---|---|
| 豪州の同面積2,500m²、120区画 | 平均ln(種最大高)の標高傾きはほぼゼロ |
| 豪州の生息地調整・区間除外 | 負の符号は安定しない |
| 豪州の50m標高帯別 | 生息地調整と区間除外を通じて頑丈な負勾配は残らない |
| 欧州・豪州を同じAusTraits高さ定義で比較 | クロアチア・ボスニアは負を維持、パルマは不安定。欧州から豪州の予測改善は得られない |
| 北京・パースの同一LEDA指標 | 各都市各年3地点、形質不足と管理型の交絡。再現性を推論できない |
| 中国高標高・南阿蘇・東日本の追加原著 | 公開資料の集計から必要な完全区画行列を再構成できない |

豪州の標高はSRTM推定418–512m。欧州既存2研究の範囲とは厳密な共通域がない。欧州は駅全域または200–800m²の調査で、豪州2,500m²と面積もそろっていない。国間予測はこの制約を持つ外挿である。形質は現地個体の背丈ではなく、構成種の成人最大高を用いた群集構成指標。

原PDF・AusTraitsを再取得し、標高を再照会する再計算を実装。草丈の定義差を統一した比較までGitHubで再現した。50m標高帯別の追加検証も[原資料再計算44679576239](https://github.com/zuizui0223/tetsu/actions/runs/44679576239)で全保存値と一致した。分析コードと集計は[PR #33](https://github.com/zuizui0223/tetsu/pull/33)に同期し、mainへの統合はしていない。詳しい検算・原資料・推定範囲は[調査記録](tetsu_v303_nonEurope_source_expansion_audit_ja.md)に記載。

## 何がまだ必要か

国間で標高帯・面積・生息地を同時にそろえた比較は未成立。確認済み原資料を再集計しても、未記録の区画内種組成・面積は復元できない。種数希薄化は面積統一の代用にならない。

この部分を進めるには、既存研究と共通する標高帯にあり、実調査面積・鉄道ゾーン・管理・完全種リストが地点ごとに結合できる独立の欧州外データ、または既存著者の未公開区画記録が必要。著者への連絡は送っていない。全球的な再現条件の特定を完了したとは扱わない。

## 論文への含意

現段階で主張できるのは、欧州内の一部で頑丈な草丈構成の地域分化がある一方、標高の同じ係数を別地域に移すことには限界がある、という範囲。成功した標高帯・形質被覆条件だけを選んで普遍性を主張しない。地域分化そのものと、標高による予測可能性を分けた構成が妥当。
