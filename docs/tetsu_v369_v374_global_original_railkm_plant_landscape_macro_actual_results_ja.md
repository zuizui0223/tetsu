## v371：データ取得後に初めて実行した大陸外予測

元source [GitHub Actions #45379245943](https://github.com/zuizui0223/tetsu/actions/runs/45379245943) **SUCCESS**、v371 [source artifact #14911834608](https://github.com/zuizui0223/tetsu/actions/runs/45379245943/artifacts/14911834608)、合成テスト9/9成功、原v369/v370/WorldClim/NaturalEarth source SHA照合の元統合解析。コード `scripts/analyze_original_world_railkm_plant_richness_Jaccard_v371.py`、事前設計は `tetsu_v371_true_global_rail_plant_turnover_macro_source_frozen_ja.md`。

**M0**：元出現種の`log1p(richness)`を、元photo観測数と異なる観測者数、WorldClim BIO1年平均気温/二乗、絶対緯度/二乗で説明。隣接格子景観Jaccardは観測数・観測者数・種数の幾何平均と差、気温平均と差、緯度・近隣方向を説明に加える。**M1**：同モデルへ実`log1p(鉄道km)`、Jaccardでは隣接2格子の鉄道km平均と差を追加。Ridge λ0.1、元1000km地域ブロックで均等重み、学習側のみ説明変数標準化。**大陸を丸ごと一つずつ除外した予測結果**でM0−M1のMSEを検証。隣接pairを独立の野外研究と誤認せず、6大陸foldの等重み平均を報告。

**重要な二つの新しいsource結果：**
1. 鉄道kmは、本当に全球記録種数を予測する**追加の相関情報**を持ち、100km・200km・6大陸ホールドアウトで5/6大陸の平均的予測改善があった。これは鉄道路線本数や単純な都市集積ではなく、元実鉄道線分WGS84 kmの説明変数である。ただし**道路・都市化・人口/土地利用、観測者の路線アクセスは未統制**。改善を鉄道による多様性の因果的増加と呼ばない。
2. 景観間種組成の類似度への鉄道延長の追加効果は**解像度に依存し、200kmで逆符号**。鉄道に沿う種輸送による全球均質化（より類似する）は**本解析では支持されたとは言えない**。100km JaccardのMSE改善は実数でも0.0000317と小さく、200kmでは負。

地域による差も大きい。100km植物種数はアフリカ+0.002508/アジア+0.001613/欧州+0.009051/北米+0.007206/南米+0.004428、オセアニア−0.004068（すべてM0−M1 MSE差）。200km植物種数はアフリカが負（−0.001869）、他5大陸が正。**6大陸は標準化された6鉄道植物調査ではない**。大陸単位は地理の外挿評価であって物理的に独立したフィールド実験ではない。

- [v374全球線路長比例の独立2048点でWorldClimを真の鉄道中心線座標で取得 #45379383994](https://github.com/zuizui0223/tetsu/actions/runs/45379383994) SUCCESS、10/10テスト。元[2048点PPS真正乱数SOURCE #45373590287](https://github.com/zuizui0223/tetsu/actions/runs/45373590287)から**2,023点**が確実に元自然陸地・元WorldClimを持ち、冷涼<8℃**556点（27.48%）**、温帯8〜<20℃**1,132点（55.96%）**、暖域>=20℃**335点（16.56%）**。全有効点の元source BIO1平均**12.242℃**。100km cell-centerとの判定食い違いは同大陸/温度valid1,949点中119点、**6.11%**で線路直接点−格子中心平均+0.275℃、200kmは1,885点中193点、**10.24%**で+0.503℃。これは**粗格子中心という代表点の配置誤差であって鉄道が周辺気温を加熱した証拠ではない**。比較する温度差の次段では実ライン座標とセル気候を区別する。

## 科学的な境界と強い反証の次段
- 真のGIS網が存在すること、景観記録植物相が鉄道kmで予測できることと、**植物が線路敷内で定着・繁殖・移入/運ばれたこと**はそれぞれ異なる。現時点のglobal sourceは非定面積、観測アクセス/機会偏りが多大で、`geoprivacy`が元S3 schemaにないため細粒位置を根拠にできない。
- v371の正の「種数追加予測」は**source公共写真に記録される種数**の予測で、路線沿い真正植生の定面積種多様性と読み替えない。都市化・道路・人口・土地被覆、農地・地形を含む非鉄道インフラのproxyが未調整。そこで**v375大陸・気候帯・緯度帯ごとの原鉄道km入替に対する局所性の負対照**を結果を見た後の診断として追加し、真の地図配置を壊しても同程度に種数予測できるなら鉄道独自の関係はさらに弱くなる。
- 熱ニッチ仮説H3は全球species-specific独立温度選好源EIDC原全件を取得できず**未実施**。Global WorldClimセルのBIO1は説明変数であり植物の温度適性値でない。
- 機能的収斂H2もまだ未実施。NHM ADEPT 2026のWFO対応59,369被子植物・life form/dispersal/heightなどの元メタデータ/CKAN source schemaは[v371a源SUCCESS #45376217612](https://github.com/zuizui0223/tetsu/actions/runs/45376217612)だが、元全traits csvと全球iNaturalist種への結合・欠測監査・全球railpoint botanist communityは未完成。
- 元世界2048 railkm確率標本は**潜在鉄道上のGIS点**で、植物を採ったフィールド区画そのものではない。世界中で鉄道上の植物相の収斂や、列車散布の機構まで論文化するには、複数気候帯の**真の軌道内／周辺の定面積植生**かgeoprivacy検証済み原植物出現データ、同等努力に統制された植物/道路対照が必要。
