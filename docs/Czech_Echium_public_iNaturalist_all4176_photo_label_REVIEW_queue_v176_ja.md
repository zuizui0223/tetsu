# 鉄 v17.6：画像を再配布せず4,176個の公開iNaturalist観察を実測ラベル化する台帳

更新：2026年11月15日。これは**写真の花可視性や草丈を既に測った研究結果ではなく、真のsource観察IDを使って、今後同じ基準で人間が実写真を判定できるようにする作業台帳**。従来のCC0/CC BYで画像をGitHubに転載する要件、同年月10km以内で別撮影者を強制した1:1ペア制約を撤廃している。

## なぜこの工程を作ったか

1. 独立の植物群集データ [CzechVeg原本2,510,340件×真正39鉄道駅種リストのsource監査 v17.4b](CzechVeg_original_39station_rail_context_to_all_Echium_photo_annotations_v174_v175_ja.md)から、*Echium vulgare* は39/39駅、同じCzechVeg元出版研究・地域・年代・面積帯の鉄道文脈の出現率差が**+6.909ポイント**だった（本物の線路への選好・局所適応の実測値ではない）。元CzechVeg中当該種が観測された研究は14本。写真解析の事前候補種として一定の根拠が残る。
2. 元 [v17.5全4,235写真記録での公式の開花可視性注釈の再監査](https://github.com/zuizui0223/tetsu/actions/runs/43711977035)は、公共に公開された観察のうち**4,176件の種・日時・座標が監査可能**と確認した。だが「開いた花が写真に見える」441件に対し、「写真に花・果実・種子が見えない」が22件、未注釈が3,706件。線路30m側はFlowers21／明示的陰性1、100–1,000m対照はFlowers73／明示的陰性1。**未注釈を0（非開花）へ補完すると偽陽性になりうる**ため、実際の写真ピクセルを元サイトで表示し、均一な目視ラベルを付ける必要がある。
3. 元v17.1のCC0/CC BYのライセンスで画像そのものを再配布する方法は、将来現地で個体の開花が早くなるかの推定には必要ない。元の写真は元著作者のiNaturalist公開ページ上で閲覧して、**実判定ラベルと元観察IDだけを引用**すればよい。

## 4ファイルと使い方

GitHub Actionsのアーティファクト内に以下の内容を分けた。

1. **original_public_observation_REVIEW_FIELDS_BLANK.csv**：真正公開観察ID4,176件、元の公開iNaturalist観察ページへのリンク、sourceの機械生成したreview_token、**空欄の花の開花可視性・同定可能性・全株の可視性・物理的な尺度の有無のレビュー欄**。**既存の開花注釈と鉄道距離・群区分は非表示**にしたが、iNaturalistページ本体の注釈と所在地は閲覧者が見ることがある。
2. **source_original_2023_rail_LINE_context_NO_coords.csv**：同じreview_tokenに紐づく、元観察の真の日時/DOY、年月、original 2023年Czech OSM鉄道Polylineまでの実GIS距離、公開位置精度、10km単位に**粗くした元地域格子**、観察者のグループ化用疑似化トークン、元iNaturalistの公式annotation状態（open flower／explicit no photo structures／buds／fruits／未注釈）。公開観察ID・正確なlat/lon・ユーザー名・元画像URLは入れない。
3. **FIRST_WAVE_356_public_obs_REVIEW_FIELDS_BLANK.csv**：上記元4,176件に対応した表のうち、近線路元178件と、画像の元annotationの有無を見ないで抽出した対照178件。先に**花が写る／見えない／判定不能**を同一基準で人が独立に判定する用の開始標本。
4. **source_qa_counts.json**：元の4,235→4,176、near178、対照725の元source数と、第一波356の出典を監査したreceipt。実画像を判読した0件を観測済みの形質ラベルとして数えない。

元の写真を直接転載せず、公開元観察ページへリンクするだけであるため、**写真ライセンスを学名・元観測情報の閲覧・人手判定の除外条件にはしない**。一方、外部サイトの元写真を画像コレクションとして再公開する場合には引き続き別の著作権・原写真著者の表示・利用許諾が必要。リンク先の画像を再配布可能と扱うわけではない。

## 判読ルール：開花の始まりでも遺伝的適応でもない

**photo_visible_open_flower** の唯一の陽性判定は、写真中に対象種の開いた花が少なくとも1つ確実に見えること。**no**は、対象種の画像で開いた花が目視できないことだが、元植物が生理的に開花していないこととは違う。対象植物が画像の一部しか写らない・個体が複数でどれが対象か分からない・ピントが悪い場合は**uncertain**とし、無理に非開花へ補完しない。

可能なら観察距離を伏せて2名が独立評価し、評価者の一致度と不確実な例の再判定を記録する。今回の作業台帳だけで**真の二重盲検にはならない**ため、他者へ示す論文ではiNatページに生育地地図や元annotationsが見える可能性を開示する。2018–25年の写真の開花状態は**初花日の本人観察値ではない**。

ラベル完成後は、元距離帯近接/遠方で観察される「開いた花が写真中に見えるか」の**条件付き関連**を対象とし、撮影日DOY、調査年、季節、地域格子、観察者グループ、公開位置不確実性、元同種種プール・撮影機会を調整する。第一波の抽出率、iNaturalist観察が生育地点の無作為調査ではないこと、元鉄道管理圧・実列車風・草刈り履歴がないことを明示する。花の遺伝的な前適応、同種の真の花期開始日、草丈の絶対値や繁殖成功はこの段階で測れない。

なお、全球・欧州全域の本来のマクロ研究には**国別公開観測の大規模収集と対応した鉄道線形・道路対照**が必要であり、今回のCzech矩形の4167などを全球数と称さない。
