## 証拠レベルと残る交絡

1. **確認できる元生態的パターン**：元真正現地駅39のうち品質ゲート14駅で、駅同士のLEDA種中央値に基づくCWM距離は、同じ駅を中心に10km以内から採った別著者・非交通文脈・真GIS座標別の参考5plot群集同士の距離より短い。観測方向は種数希薄化、21plot割当の変化、元路線区間除外、100m座標セル独立にも保たれた。
2. **異なる推定量**：v23.7では元39駅の**鉄道内部の種出現頻度・駅面積・元5路線固定の再配置帰無**に比べ、駅の実CWM距離は**大きい**（観測0.1652対帰無0.1204、正+0.0448）。今回の**外部の周辺小plotプール**に比べると、元14駅のCWM距離は**小さい**（差−0.427）。内部帰無と外部参照は全く違う分母なので見かけの逆符号は理論的矛盾ではない。
3. **最大の限界**：鉄道は大型駅全域の3ゾーン植物リスト、参考は5小plotの元別々の場所・目的に由来する合成種プール。元sourceの種数を揃えても**生息地混合、調査面積・頻度、都市化、標高、土壌・鉄道管理、年の不一致**は消えない。今回の参考は植生クラスや土地利用を等しく揃えていない。
4. **座標精度の限界**：元CzechVegのレコード`PRECISION`は>0〜250m。セルを100mに丸めて一意にしても、真の可能位置の不確実性円（半径最大250m）は重なりうる。**完全な現地の物理独立を証明したとは報告しない**。
5. **因果の停止**：同時代の旅客・貨物列車本数、実際の鉄道seed transport origin/destination、管理・除草剤・風による局所生存選択、種内適応遺伝子は元dataから測れない。鉄道が植物を世界的に機能均質化する、元のsource plot ID/座標差が選択進化そのもの、とは主張できない。
