# eBird（GBIF EOD）による鳥の「鉄道またぎ類似度」の独立観測網での再現（2026-11-26）

実行：[GitHub Actions #45671791228](https://github.com/zuizui0223/tetsu/actions/runs/45671791228)（成功）。データ：GBIF配信のeBird Observation Dataset（2023年1.81億、2024年1.95億、2025年2.14億件）、鳥類、2023〜2025年をまとめて使用。現役線のある200 km格子2,236個に問い合わせ、記録あり2,137、ゲート（記録50・観測者5・種20以上）通過1,960、隣接ペア2,965。種・観測者の切り詰めは0格子。

設計はiNaturalistの鳥の解析と同じ（同じゲート、同じペアモデル、同じ共変量、地域ブロック単位の誤差）。**結果を見る前に固定した主要指標**：200 km・陸地50%・端点固定効果のJaccardに対する現役線またぎの効果。iNaturalistの値は+0.017［+0.003, +0.031］（2023〜24年平均）。

## 判定

- **主要指標は再現せず。** 向きはiNaturalistと同じ正だが、大きさは約半分で、区間はゼロをまたぐ。
- 副次的には、Simpson類似度（種数の少ない側に対する共有割合）の端点FEで、現役線またぎが正、現役−廃線も正で区間がゼロを外れた（陸50%・80%とも）。iNaturalistでも鳥のSimpsonは正だった。ただし副次指標で多重比較の補正はしていない。
- ブロックFEでは効果はほぼ0で、iNaturalistと同じくモデル依存。
- 大陸留保の予測は改善しない。

## 限界

- eBirdとiNaturalistの観測者は一部重なる。GBIF版EODは保護上の理由で一部の種を含まない。
- 2023〜2025年をまとめた値で、年ごとの検定ではない。
- 地図上の線路の交差であり、列車の運行量ではない。
