## 重要な設計上の改善

v19.1–v19.3はTH/TF等、元植物組成に基づくSYNTAXON植生分類から『自然アナログ』を定めているため、同じ分類を使う対照群が種名・生活形・散布戦略の構成で似やすくなる循環性がある。v19.4は元植物組成からの分類を一切選定に使わず、元標高・傾斜という非植物データから比較候補を構築した。これは重要な**非循環的対照の支持域検証**だが、まだ生物群集Jaccardなどの推定結果ではない。

元CzechVeg source RAILはHABITAT/LOCALITYの文脈テキストであり、実線路敷地・バラスト基質の物理確認がない。参照候補の元非交通語欠如も自然生育地の保証にならない。傾斜と標高が一致しても自然のアナログ基質を再現できるわけではない。標高を追加しても観測努力や調査目的、サンプルした原著論文の違いは未測定。

v19.5で同じ生物データ2,510,340行を読み、元同一RAIL plotを保持して『元標高一致の参照 vs 全非交通背景』の地域間種名・属組成を比較する。標高±100m、標高±100mと斜面±10度の2設計、種数一致の感度を別々に報告。各地域から1元RAIL plotと独立参照plotを1つ選ぶ原観測内サンプリング反復は独立現地データの95%信頼区間・p値ではない。
