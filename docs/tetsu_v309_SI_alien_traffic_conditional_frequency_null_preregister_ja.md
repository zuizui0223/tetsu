# v309 解析前固定：外来植物の共有だけは交通強度と対応するか

2026-11-21 JST。**v305・v306の結果を知った後の探索的補足解析**。結果を確認する前にこの解析仕様・主指標と停止条件を研究ブランチへコミット。独立事前登録でも独立野外追試でもない。

## 中心仮説と帰無

スロベニアの真正9交通区間×27地点の36相互依存dyadでは、2020貨物本数とBS∪BT合成群集の区間間Jaccardの傾きは+0.015538（都市化**非調整**）。v306では全89実植物地点の種数×種頻度保存技術帰無の観測超過+0.009504だが、原年×単複線保存帰無では超過−0.000019で完全に消える。

一方、source明示的外来植物29種だけの係数寄与は+0.010394と大きい。この**観測後に気づいた局所的な候補**に関し、全植物の交絡で消える中でも「外来植物の実同一種共有」が植物種数とtaxon frequencyの期待から増えているかを主検定する。これにより陽性でも因果的列車散布・鉄道外自然植生との分離を実証したことにはしない。

## 測定対象と主仕様

1. 原Šabić et al. 2026 XLSX SHA256 \`26be7ca9513dd54136d4ec499d8413c1cb288045f87fe3cf8814731f2edac99f\`（89元植物地点、15線区）、公式2023駅距離 PDFおよび2020 Eurostat 真双方向物理区間再構成（27地点、9物理区間、5国鉄路線）を既存v306読込関数で再取得・検算する。現地点×taxon/GPS/公式駅距離原表は再配布しない。
2. **主ゾーン：BS∪BT**（raw観測種寄与が最も明瞭でv306年×単複線で消えた組合せ）。**主群：著者の \`Nativeness.status\` が明示的にalienを含む分類群**。原著source statusが空欄なら「not explicitly alien = native+unknown+crop混合」であり在来に偽装しない。原著全statusについて全原ラベル・未知割合を監査する。
3. source9交通区間×36 dyadのsite pair平均Jaccardについて、共有外来種の寄与だけを \`#(shared explicitly alien)/(#(all observed either taxa))\` として群別に分解。これは「外来種だけで計算したJaccard」ではない。分母を全植物に固定することにより元full Jaccardを共有種ごとに正確に分解できる。群の観測係数の和（明示外来とそれ以外）=真の全植物の係数（誤差1e−10）。
4. 貨物は2区間のlog1p 2020年間本数の平均、log1p(真正サイト間平均直線距離)を共変量として線形OLS。別モデルのurbanは**未再取得**のため同時調整した係数と取り違えない。
5. 2チェーン×199 technical checkerboard draw、burn8000・spacing400・種×元89地点richnessと元taxon出現頻度を完全に固定。**主帰無**＝原著調査年2022/23×単線/複線ごとに同じ種の出現頻度まで保存。**副帰無**＝全89地点での種数と頻度のみ保存。描き直した元matricesの同じサイトpairの外来のみ係数から実−帰無平均・帰無分布の技術順位（p値ではない）を計算。元観測全Jaccardに対するv306保存係数との完全一致をゲートにし、元source区間交通ラベルそのものは固定。
6. 一つの検定モデルに観測original dyadを入れ、既存v306と全zone BS、BT、BS∪BTの元実貨物係数・元外来群係数を1e−9以内で必須再現。元source field species incidenceを別ツールで作ったふりをしない。
7. 旧公式5線区内だけの**48交通ラベル全入替**を、source実共有外来群の係数にも同様に適用し、線区そのものと種プールの交絡に対する候補の極端度を記録。観測税種群の増分で当たりが出ても、線区内入替で普遍性は証明できない。

## 事前固定の感度・負の対照

- **BS単独 / BT単独**：真の道床肩での再現、法尻だけでの再現を分ける。
- **strict annual**、**原著Epilobium/Phragmites風関連散布類型**、**原著Bidens原型**、**status欠損**：副群、分類間重複あり。風類型もBidens原型も列車への付着・車体実輸送・種子活力の観測ではない。
- 原本群外 (not explicitly alien)を分ける。**未知=在来ではない**。全植物合計効果と外来群の係数は単純比較せず、同じ分母と同じMCMC source margin条件に限定する。
- 95% technical null percentilesは相関する抽出分布であり生態学的95%信頼区間と呼ばない。9実交通区間/36共有区間ペアを36独立野外反復と扱わない。年2015/2020の同一植物への曝露感度を独立研究とは数えない。

## 採用・反証条件

- **主候補を維持**：BS∪BT外来群の厳格source年×単複線条件付き頻度帰無との差が正、かつ元の48線区内交通ラベル分布で比較的端に位置する。次段は独立研究の同一種出現行列+駅別交通を要求する。
- **不支持**：厳格帰無との差が0か負、または48本数入替で非特異的であれば「外来同一種のネットワーク輸送がさらに支持された」と書かない。v305の二尺度は記述のまま残し、形質・種頻度のみが動く可能性を考える。
- 技術的陽性でも実調査**同時期の貨物OD、草刈り、列車風、種子活力、同面積の鉄道外近隣植物相**の未測定は残る。推論対象は同一sourceの同一種共有という群集パターンのみ。
