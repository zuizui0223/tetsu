## v19.1：原著251万植物記録を使う構成比較（解析設計）

元著者の完全2,510,340種×調査区行CSV（元Zenodo MD5 b296e5e19f03fb3bad0a8347c317f8a3）を取得し、植物群=vascular、調査区ID×学名の重複を排除。原データの全行・MD5・地域/原著出版の完全性が通過しなければ係数は報告しない。

非鉄道／アナログ側を学名・生物結果を見ずに元観察IDのSHA256で事前選定。各鉄道調査区と元植物地理地域×10年×測定面積帯が一致し、しかも元原著タイトルは異なる。非交通すべて、自然アナログTH/TF/TGだけ、双方それぞれに参考plot数最小5区を要求する。

各地域から毎回元鉄道1区と対応する参考1区をサンプルし、地域間の植物種Jaccard類似性および属レベルJaccardの鉄道−対照差を計算。500回再標本化（独立フィールドnや正式なp値にはしない）。さらに植物名は見ず、種数比が2/3から1.5の範囲にある対照だけの厳格な別感度、元植物地理地域1つ除外の符号診断を行う。全地域ではなく同じ地理的共通支持域内の結果のみを報告。

主な制限：(1)参考の独立性は**調査区と原著研究**であり、別に設計された全国的な非鉄道調査データセットではない。(2)自然アナログは植生クラス情報でしかなく、実基質管理・面積占有率はない。(3)鉄道駅全域のリストと小さな植物方形区は同じ単位として混ぜない。(4)原著の豊富な歴史記録を現代特異的な列車種子散布や遺伝適応の証拠としない。(5)種Jaccardの共通支持域と原分類名に依存し、生活形の機能収束はPladias属性を別途結合しない限り未計測。
