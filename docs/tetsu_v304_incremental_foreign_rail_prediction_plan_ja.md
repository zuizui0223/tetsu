# v304 地域背景を超える他地域鉄道情報の予測増分

2026-11-20。利用者が承認した①を先に実行する。既存結果を閲覧済みの探索的追試であり、研究全体の事前登録ではない。以下は新しい係数・利得の計算前に固定する。

## 問いと二つの異なる検証

**A：鉄道原研究留保・国内背景条件付き予測。** 旧country_validation.pyを元PDF/XLSX/CSVから再実行し、元の国別比較を再現してから使用。主学習対象は完全な原行列から頻度を計算できるCZ39、IT28、HRBA15、SI89、India16。HRBAは分割せず一研究。SK30の丸め周辺頻度は主解析から除外。Perth/Beijing各3地点は一出版として主学習に入れず外部の小標本診断とする。SIは駅でない。国内対照はCZ都市（道路へ変更を感度）、IT道路、HRBA都市（13:2で国を集約）、SI都市、India道路。これらは近隣・同面積・同年対照ではない。

対象鉄道研究を全て除いてモデル学習。学習各研究の他国鉄道説明変数も、その研究自身と評価対象を両方除外して作る。種集合もその外部ドナー2研究以上で記録され、国内背景に記録された種に限定する。対象鉄道の出現を使った種選択はしない。種20以上、学習3鉄道研究以上を支持基準にする。原研究等重み、その中で種等重み。応答は区画出現頻度であり、出現行数や国別総種数を分母にしない。

同じ対象に、切片のみ、国内背景頻度、他国鉄道頻度、両者加算の4モデル。頻度は[.01,.99]へクリップしてlogit化。切片を除く係数のL2罰則は平均対数損失に対し0.01、0.001/0.1を事前感度とする。標準化は学習行だけ。分数応答の交差エントロピーと、区画での期待Brierを評価する。国/研究別の増分、種被覆、ドナー数を全て保存。正の値は誤差減少。異なる調査粒度なので、全国背景を超える予測情報の診断までとする。

**B：カシミールの同地点・同年・同面積の局所対照。** SHA固定のMatrix_plot.xlsx、TrackとInterior1/2の3区画（各100m²）を使う。欠損セルのある区画は全種不在とせず、対応サイトをその年から除く。2014と2017を別々に分析。主対象は著者表の種名に一致し、CZ/IT/HRBA/SIの独立2研究以上で記録された種。感度は原表の厳格二名法対応全種。元欧州4研究の平均出現頻度は固定し、カシミールを一切使わない。

同地点の2内陸区画での記録有無、学習地点内陸区の種別頻度、標高、駅/駅間からTrack出現を予測する。主検証は緯度で並べた約6地点ずつの連続5空間ブロック留保。ブロック分割に植物応答を使わない。最小3ブロック、種10以上、各訓練集合に両応答を要求。

比較は局所情報のみL、L＋外国鉄道F、L＋学習地点のTrack種頻度T、L＋T＋F。Tも対象ブロックのTrackを除いて計算する。これでFが局所の種固有頻度の代理にすぎない可能性を診断する。加えて、同じCZ/ITの2国に限定した外国鉄道頻度と、同2国MIREN道路頻度を個別にLへ追加する比較を行う（国外地域・粒度は未一致）。全モデルの対象行を固定し、外国頻度だけでパネルを変えない。誤差は地点内種等重み→地点等重み、5ブロックの削除感度とブロック再標本999回を報告。5ブロックの区間を全球研究間CIとは呼ばない。

これはカシミールで較正した未使用空間ブロック予測であり、国留保ではない。同年の内陸観測を利用するため、完全無観測地点予測でも時間予報でもない。年を2独立研究に数えず、未記録を個体の不存在・死亡に変換しない。

## 判定

FがLを改善してもL+Tを改善しないなら、鉄道固有の国外情報より一般的な種頻度を反映する可能性。Fと外国道路が同程度なら鉄道特異性は未支持。国内背景を越えるAの成功だけで局所対照の問題が解消したとはしない。国留保Aと国内空間留保Bを統合した一つの効果量は作らない。失敗、支持不足、対応種限定を全て報告する。
