## Freeze actual correction logic
1. True source segment length `L=Σ_i Geod.inv(lon_i,lat_i,lon_{i+1},lat_{i+1}).distance_metres` for each Overture original WGS84 geometry. Each original adjacent pair `(at_i,id_i),(at_j,id_j)` has source graph edge weight `L*(at_j-at_i)`. For any repeated original connector pair, retain the **minimum** available source rail edge weight as in baseline; bridges/tunnels preserved and disused/abandoned/under-construction excluded for normal rail candidate.
2. Match original botanist GPS to nearest original rail source geometry in the same local UTM metric coordinate system (nearest source rail ID unchanged), with same 120m threshold and 20m disconnected topology ambiguity guard. Then derive each site’s true source `at_site` from its snapped original polyline segment: geodesic cumulative WGS84 length to previous original vertex + exact local UTM projected fractional position within that original small line segment × original segment geodesic length, divided by source geodesic L. This is the correct original fractional distance within polyline. If the original site lies outside first/last connector position interval, fail closed (cannot invent source endpoint edges).
3. Replace old *site→connector* short edges by source geodesic distance `L*(at_site-at_connector)`. Old source site graph connected component, original source site phyID, source plant species set must stay unchanged. Keep original candidate plots and original matched source raw survey data, no selection by species identity.
