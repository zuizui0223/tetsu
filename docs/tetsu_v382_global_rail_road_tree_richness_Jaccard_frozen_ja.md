# v382 全球植物種数・隣接セルJaccardの道路と樹木被覆による反証（事前固定）
v379の帰化種割合の原ソース再集計とは独立に、既存v369/v370/v376cの同じ100/200km適格セル3455/1442を出発点として、v380bとv381b原資料を接続する。道路は陸地あたりm/km²、土地率はGRIP元陸地面積/セル面積、樹木はEarthEnv4層の全セル面積当たりtree consensus（海洋含む、純陸地森林率でない）。主解析は元セル陸地率>=50%、感度>=80%、道路有効陸域率>=95%、樹木有効セル面積>=95%。同一のcomplete-case panelで全比較を行う。全世界の元分母と大陸別脱落を報告し、4大陸未満なら独立転移支持なし。元v371の1000kmブロック正規化ridge lambda=.10と6大陸holdout、元の最小標本ゲートを維持。
M0=気温・緯度・観測努力・GHSL・陸地率・樹木被覆。Mrail=M0+鉄道長、Mroad=M0+道路密度、Mboth=M0+道路+鉄道、MroadX=Mboth+道路×樹木、MbothX=MroadX+鉄道×樹木。応答はlog1p観測種数、隣接景観Jaccard。後者は元の対セル基準変数と道路・陸地・樹木・GHSLの平均及び絶対差、鉄道と道路の平均量に平均樹木との積。方向は大陸固定効果相当の重み付き残差回帰（各大陸別も記録）、推定値は記述的、p値なし。鉄道追加予測力と交互作用追加予測力を分け、正負も分ける。Hansen & Clevengerの局地距離減衰や帰化種への特異性を直接検証するものではない。全景観の植物観測であって、線路内植生ではない。道路/樹木は歴史的データ、人口や観測アクセス未調整、機構因果不可。真の原データ実行成功前は結果なし。
