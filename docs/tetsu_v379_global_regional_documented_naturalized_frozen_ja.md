# v379 地域仮説の全球再検証：既知帰化種割合（凍結計画）
v378aの精密な植物位置公開状態の問題とは独立に、v369/v370/v376cと同じ100/200kmの全景観観測を再集計する。2025年iNat同一S3 snapshot、元の100/200km固定グリッドと元の適格性、同じWorldClim、NE、GHSL、真の全球鉄道長。全大陸を対象にし、事後に地点を選ばない。v369集計には種別IDが含まれないため、原13.7GB gzipを再ストリームし、原SHA、全行数、両解像度の全セル観測数の完全一致を要求する。
原GloNAF 2.02 DOI 10.5281/zenodo.17105725 (2025-09-12版)。公式非重複地図とflora2/taxon_wcvp/regionをMD5固定。公式地域コードと図形を照合。iNatの原分類階層でTracheophytaを厳密に抽出し、活性種・種以下親種をv369と同一に処理。受容種の二名法完全一致のみ。異なるWCVP受容IDに対応する名前は分子から除外し、分母はiNatの全対象維管束植物種。GloNAF非掲載や名前不一致は在来ではない。明示的帰化種が観察された割合の下限型記述量で、全外来種割合や植物個体数ではない。
主解析では各グリッド全域をWGS84で0.3度拡張した矩形を単一のGloNAF原非重複地域が完全に包含する場合だけ地域を割当。位置秘匿の情報欠損を解決するものではなく、粗い地域割当誤りを軽減する保守的な近似にすぎない。日付変更線・地図境界・沿岸・小島で支持不足となりうる。感度は拡張なしの矩形。同じ元の全球分母を報告する。いずれも正確な個体位置の分析・公開を行わない。各セル>=20維管束植物種、元の努力ゲートを維持。両粒度と両地域ゲートを全報告、追加の事後選択なし。
主推定量 = GloNAF地域の掲載種名に完全一致する観測済み維管束植物の異なる種数 / 当該セル観測済み維管束植物種数。
予測：元の6大陸丸ごとholdout、1000kmブロック重み、λ=.10のridge。基準 = 気温・緯度・観測努力・2020 GHSL建成面積・観測全植物種数・地域の既知帰化種プール規模、拡張 = +log1p(実鉄道km)。同一対象行で比較、割合予測を0–1にclip。適格大陸の不足はNA/限定的と明示。予測改善は関連の向きを意味しない。
方向：地域内の比較を別途実施。各地域>=5適格セル・>=2空間ブロック・鉄道長の変動を要件とする。地域内加重demeanで地域固定効果相当、全域と各大陸別に元の気温・緯度・努力・GHSL・観測種数を調整した加重OLS。残差化で共線性を検査。生態的な推定値を正負問わず記録、少数地域・ブロックの推定値を普遍性とはみなさない。方向のCI/pを未監査の疑似反復から作らない。
本検定の位置づけは景観レベルの帰化記録割合と鉄道密度。H1の間接的な広域版のみ。道路長・人口・森林率・利用アクセス未調整、直接の鉄道生息地やHansen & Clevengerの距離減衰・列車散布・競争・定着・侵入の因果推定ではない。2025 iNat、2020 GHSL、2026 rail、GloNAFは異時点。元の種/観測者IDやGPSは公開しない。全データゲート成功前は生態結果なし。
