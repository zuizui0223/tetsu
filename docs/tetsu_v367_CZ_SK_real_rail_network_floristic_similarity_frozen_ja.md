## Original-source technical erratum before accepting a Slovak ecological result (2026-11-24)

The first original v367 Slovakia run failed the original source "physical GERS path should not be >50m shorter than original station-to-station WGS84 chord" check. The subsequent QA showed all 171 original GERS route lengths ARE geometrically consistent: direct original mapping from the full source physical GERS pair dictionary never undershoots geographical chord by >50m (true max geometric chord−network = -28.693 m; GPS-to-track offset bound max42.37m). **Reason:** the original biological analysis accidentally used Python `network.get(i,j)`, which asks for scalar key `i` with default `j`, so silently returned the second **station index** (1..18) instead of the true mapped GERS distance. That run's apparent path min/max 1–18km, ratio0.639, and associated source biological slopes are **INVALID and were not committed**. It was a software-indexing bug, NOT source evidence that trains use shortcuts or Overture rail mapping has invalid geometry.

The source helper `station_pairs()` now uses `network.get((i,j))` and requires a corresponding `network.get((j,i))` symmetric original physical source path. A new synthetic regression deliberately makes site ordinal and true GERS route lengths different, and checks that the actual array uses the tuple-keyed geodesic source route and fails if the reverse pair is altered. All 171 true GERS route paths and 19 original DMS station coordinates must be reverified after this correction. No retuning of original Jaccard model, geographical range, source richness, null draws, sampling studies or human-selected calipers. **No Slovak source effect can be accepted until successful corrected actual original GitHub Actions run.**
