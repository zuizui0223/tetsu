# v388 観測努力に対する種交替の感度検証（新規結果算出前に固定）
v386の同じ原資料・同じ100/200km・陸地50/80%の全4パネルから、観測記録数と観測者数に極端な差がないペアを限定する。元の種交替係数とセル・ペア数の再現を要求。1)全ペア、2)両端の記録数と観測者数が各2倍以内、3)さらに観測種数が2倍以内、4)条件2かつ両端それぞれ200記録以上・20観測者以上。全4条件を報告し、効果方向で閾値を変えない。主条件2。条件3は生態学的応答への条件付けになりうるため記述的感度のみ。100ペア・20端点ブロック未満は全球回帰を支持しない。元の道路・樹木・都市化・気候・観測努力・種数共変量と大陸FE・空間ブロック重み、端点ブロック削除、大陸holdoutを維持する。元の観測記録数/観測者数は完全な努力指標ではない。観測者の重複や種の検出確率を揃えたものではなく、個票がないのでカバレッジ標準化やoccupancy推定はしていない。β多様性の符号の頑健性のみ、因果や列車輸送を主張しない。v383,v387は別のsource workflowで継続中。
