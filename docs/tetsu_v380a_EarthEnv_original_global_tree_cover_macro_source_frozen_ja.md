# v380a 全球の森林・樹木被覆情報の接続（効果計算前の独立ソース）
先行研究 Hansen & Clevenger 2005 の森林による交通回廊侵入の抑制を、既存の100/200km全球マクロ解析に拡張する準備。EarthEnvの公式1km consensus land cover full v1.0 (Tuanmu & Jetz 2014 GEB 23:1031–1045, https://www.earthenv.org/landcover) の1〜4類（針葉、常緑広葉、落葉広葉、混合その他樹木）を全世界で取得。原ラスターの4層の格子、投影、寸法、値域、SHA256を監査する。4層同時有効な画素の樹木カテゴリ割合を和とし、丸め上の100超過を明示監査、104超は失敗。EPSG6933等積投影で元画素中心をv369の固定100kmグリッドへ割当、投影画素面積で加重。境界で画素を分割しない近似であり有効画素面積/セル面積も出す。200kmは厳密2×2集計。未知をゼロ補完しない。
これは1990年代〜2000年代の複数衛星プロダクトから作られた樹木カテゴリのconsensus指標で、2025の実森林被覆率・局地林内抵抗性・樹冠閉鎖率とは異なる。90N–56S原範囲。近年の森林検証には独立2020以降データを別途追加する。CC BY-NC 4.0。原ラスターは再配布せず集約のみ。今後同じGloNAF適格セル、元GHSLと観測努力・気候・道路長に条件付け、鉄道主効果＋樹木主効果＋交互作用の大陸holdout／方向を評価する。v380aはデータ接続の実行のみで効果量なし。GloNAFデータ修正と独立に走らせ、植物アウトカムによる選別はしない。
