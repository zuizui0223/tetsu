## 評価の仕組み

地域内の同じ道路と同じ現地サイトを固定して、その道路に含まれる**複数の地点間**のJaccard非類似度を元各ゾーンで計算済みの結果から読み出す。道路内の地点ペアを独立標本にせず、同じ region に属する各道路を等重み、その後17 Regionコードを等重みする。17 Regionを17独立の国・調査論文と呼ばない。

- `D12 = β(Plot1道路際) − β(Plot2中間)`
- `D13 = β(Plot1道路際) − β(Plot3内陸)`
- `D13 − D12 = β(Plot2中間) − β(Plot3内陸)`。

負なら道路際の方が地点間で植物種構成が近い。差をとったときPlot1は厳密に相殺される。異なる参照に対する推定差を、道路自体の効果と読み替えない。種数等化は元計算で同じSite×Yearの三ゾーンを同時に希薄化した派生系列。

## 機能群集（葉群高・種子重の2D CWM）は母集団の支持を厳格に区別
