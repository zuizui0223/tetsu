# v313 外国鉄道頻度とKashmir記録遷移：事前固定した探索解析設計

作成日：2026-11-21。基準コミット：5bca2827f1df6d74ea52bbc578e89abe5aff9ca3 (v312)。
本書はv313の対象効果を計算する前に固定する。v304の横断面結果、v258–263の局所量と記録持続の結果は既知であり、独立した盲検の事前登録ではない。

## 問いと位置づけ

欧州の複数の鉄道調査で頻出する植物は、Kashmirの2014年から2017年の記録遷移について、2014年の国内頻度・被度・隣接区画の記録を超える情報を持つか。その情報と関係の方向は、同じトランセクトのTrackとInterior Plot 1 / 2で異なるか。

v304の同年のTrack記録予測を時点間の条件付き遷移へ拡張する。Slovakia2025の413種頻度は2026-11-17のreplication_auditですでに比較済みであり、新規反復として加えない。欧州データの一部はKashmirの2017年より後の調査なので、これは遡及的な時点間関連の検証であり、当時実行可能だった将来予測ではない。

## 原資料と対象

- 外国指標はv304と同じ4研究：CZ39, IT28, HR_BA15（2国を含む1出版研究）, SI89。各研究の全鉄道地点の出現率を計算し、4研究を同じ重みで平均する。ある研究の完全な調査リストにない種はその研究の頻度0とするが、その国の植物相に存在しないという意味ではない。各種の指標はlogit(平均率)とし、率を0.01–0.99で切る。
- 対象はDryad DOI 10.5061/dryad.0p2ngf20hの原本Matrix_plot.xlsx。原本SHA256は529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474。v254の独立ZIP/XML読取とv304のpandas読取で区画ごとの記録集合を照合する。
- Track / Interior Plot 1 / Interior Plot 2は各100m²。同じトランセクトの3区画×2014/2017が全て観測された完全ペアのみを使う（既知の見込み27トランセクト）。全面欠測は0に置換しない。Embankmentは区画比較に含めない。
- 原本のtaxon列を既存eu.binomialの固定規則で整形し、重複する種キーがあれば停止する。主対象種は(1)原本全地点・全4区画のいずれかで2014年に記録され、(2)外国4研究のうち2以上で記録された種。2017年のみ記録された種で対象集合を広げない。
- 種集合は既知の2014年の地域インベントリーに条件付ける。外国研究・Kashmir出版物を独立な数百の研究と数えない。Kashmirは1回廊・1出版研究である。

## アウトカム

1. **主解析：記録持続**。2014年の対象区画に被度>0の種×区画×トランセクトを対象に、2017年の被度>0を二値目的変数とする。
2. **副解析：新規記録**。同じ基準種集合のうち2014年に対象区画の被度=0の行を対象に、2017年の被度>0を目的変数とする。地域に2014年にすでに知られていた種の別区画への記録追加を意味する。

これらは個体生存率、検出率補正後の占有率、新たな侵入・定着・列車による種子移動を直接推定しない。

## ブロック外予測と共通の基準モデル

完全ペアのトランセクトを緯度で並べ、numpy.array_splitで連続した5ブロックに固定する。同じトランセクトの全種・全区画を一緒にhold outする。2017年の記録は学習側の目的変数にのみ用い、説明変数・対象選定・分割に用いない。説明変数の標準化は学習行だけで行う。

M0には区画別切片（全体切片+内陸2指示変数）、標高、駅/駅間指示変数、および次の区画別傾きを含める。
- 2014年の同区画種出現率のlogit。学習側トランセクトから計算し、学習行自身については当該トランセクト全体を除外する。検証側は学習側全体を使う。分母は該当区画の全学習トランセクトで、対象アウトカムのrisk setに限定しない。
- 同一トランセクトの他の2比較区画の2014年記録率（0, .5, 1）。
- 主解析のみ：当該区画の2014年被度log1p。

各局所共変量の傾きを3区画で別々に持たせ、外国指標×区画が、既存の局所頻度×区画の違いを代用しないようにする。標高と駅区分は共通傾きとする。モデルの全ての追加比較でM0は同一である。

## 入れ子モデルと方向の分離

正則化ロジスティック回帰はv304のfit_predictと同じ実装を再使用し、各foldの学習重みを合計1に正規化する。学習は3区画それぞれの対象行で重みを正規化した後、Track=1、Interior1=.5、Interior2=.5として合わせる。

- M0：上記の2014年国内基準。
- M1：M0 + 外国指標Fの共通傾き。
- M1b：M1 + F×内陸対比C（Track=0, Interior1=+1, Interior2=-1）。
- M2：M1b + F×Track指示変数。

共通列の符号・標準化・ペナルティを入れ子モデル間で統一する。主ペナルティλ=.01、固定感度解析λ=.001/.1。結果を見てλを選ばない。

予測比較：
- M1対M0：外国頻度の全区画共通情報。
- M2対M1：区画別傾き全体の効果（内陸同士の違いでも改善し得る）。
- **M2対M1b：内陸同士の違いを許した上でTrackの傾きを追加する比較**。

改善はloss(reduced) − loss(full)で、正が改善。M2の係数を各foldの標準偏差で戻し、Track−内陸平均、Track−Interior1、Track−Interior2の外国指標傾き差を併記する。予測改善だけではTrackで正の関係が強いとはいえない。係数は正則化された条件付き関連であり、独立した因果効果や有意差ではない。

## 集計と判断

主指標はholdoutのBernoulli log loss (nat/対象記録)、副指標はBrier score。まず各fold×区画で対象行の平均lossを求め、Track=1、Interior1=.5、Interior2=.5を合計2で割る。主集計は5foldの等重み平均とし、対象行数が多いfoldで結果を支配させない。各fold、各区画の対象行数・陽性数・イベント率を残す。

対象行が0の区画foldはNAとし、重みを黙って再配分しない。そのfoldの全区画集計はNA、区画別の値は残し、集計の有効fold数を明記する。陽性数0でも対象行があればlossは定義される。各比較の正のfold数、fold別値、1fold除外時の等重み平均範囲を報告する。5ブロックだけから母集団の信頼区間を作らず、種×区画の依存した多数の行を独立反復とするp値も出さない。

「Trackで強い」という解釈には、M2対M1bの改善、両方の内陸に対する符号、ブロック間・λ間の一貫性を同時に確認する。条件を満たさない場合はそのまま不安定・支持なしと報告する。結果に合わせた種集合・参照区画・λ・主指標の変更はしない。

## 実行後の原著照合による用語訂正（2026-11-21）

固定時点で原本値を「被度」と呼んだのは不正確だった。[原著§2.2](https://besjournals.onlinelibrary.wiley.com/doi/full/10.1111/1365-2664.13961)はspecies abundanceと記述し、100を超える原本値もある。以降は「原本の種別abundance（記録量）」とする。>0による二値化、log1p変換、対象・分割・モデルは一切変更しない。また、4つの欠測は4区画行にそれぞれ1セルずつ存在する部分欠測であり、区画全体が未調査だったという意味ではない。既定の完全ペア選定によって4トランセクトが除外される。
