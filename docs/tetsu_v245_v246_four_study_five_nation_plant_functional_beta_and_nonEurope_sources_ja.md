# 鉄 v24.5–v24.6：独立4原著・欧州5か国の鉄道植物「機能的共通性」の本物の広域検証

2026-11-17 JST。これまでの主題「鉄道のような繰り返し設置された人工環境は、地域が異なっても植物を同じ機能的形質へ収束させるか」。**結論を先に**：本物の鉄道植生4原著・5か国で**元鉄道内の地域別・種数・種出現頻度を保持する帰無に比べて、実観測の地点間機能重心距離が大きい**方向で再現。ただしその帰無は**独立した自然植生との対照ではなく**、「世界の鉄道では地域植物相より機能的に分化する」とは全く言えない。チェコ14駅の独立した局所的非交通文脈植生5plot/駅との比較（v24.4）は逆に、鉄道の地点間機能重心が局所参照に比べて**相対的に近い**という別推定量を示す。**この2種の異なる帰無を決して無条件に同じ効果量へ合算しない。**

## 2. 全原著統一の指標と、別々に定義する帰無

各実植物相内で元LEDA種中央値をspecies-equal CWM2次元ベクトルにし、2地点のCWM間ユークリッド距離を「地点間の機能的beta」の操作指標とする。同時に、元観測species-name Jaccardと各サイト内のCWM中心からの二次元trace分散を**別々**に記録。高CWM距離は「地点間の異質性」を示し、低ければ「収束」。trace分散はalpha機能幅でありbetaと同じ推定量ではない。

各出版研究**内でのみ**元サイト×種出現行列を2×2 checkerboard種入替し、各真正元サイトのLEDA既知種数と、種ごとの同じ原著地理区内出現サイト数を**厳密に固定**する。元国有線区間／著者地理区で種の頻度を固定し、観測された鉄道固有種プール以外の未取得自然植物は**元帰無に含まない**。2独立乱数チェーン×100 MCMC技術draw/研究、元出版研究3+スロベニア1を別々に処理。スロベニア15線区のうち81号は元地点1件なので、その区間内の入替を不実行として元行列を保存した。計14線区は少なくとも2地点あり合法に入替可能。生物学的な地点ペアの偽独立性や「200独立野外反復」を主張しない。

### 現在の厳密な次段
1. **最優先**：フランス71地点の元サイト×種行列をAppendix B/公式Supplementから直接取得できるか確認。標準5m²で種の局所選択を確認可能、ただし公開が無ければ結果は作らない。
2. **最優先**：中国雲南84plotの元matrixと独立対照（駅/未攪乱・土壌・緯度）を研究者が配布するか確認。直接の等方法対照となる可能性が高く、外部参照が弱いチェコ14駅に比べて意義が大きい。
3. 対照が物理的に確認された**同面積・同観測努力の鉄道vs非鉄道plot**を、気候区分で層化して比較する。元LEDAの欧州中心の観測形質が熱帯アジアに偏りなく結合するか**種対応欠損率**を必ず測定。ギルド・生活形の元source原属性と種中央値の高さ・種子重を別層の応答にする。
4. 複数国の結果は**研究・現場地点・原気候/群落分類をnested hierarchy**にして、研究単位ブロック再標本化と地域植物種プール帰無を入れる。元到達経路による貨物種子移送はODと元植物の真正到達/定着測定を必要とし、群集Jaccardだけで因果としない。

現時点で元原著4つにより検証した強い結論は**「人工鉄道の植物群集に、一律の機能重心収束を自動的に期待できない。鉄道内の地点間では、地域と元種数/種頻度から予想するより強いCWM分化が繰り返し現れる」**。これは「鉄道が地域の自然植物をどれくらい上書きしたか」と異なる問いであり、等面積の現場対照を得ない限り、生態メカニズムの推論は制限される。
