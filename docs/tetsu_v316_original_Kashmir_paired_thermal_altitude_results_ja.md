# v316：真正カシミール31地点の同地点・同年温度親和性差は標高とともに増すか？

2026-11-22 JST。v315/PR46における地域間対照の不一致を解消するため、[Rashid et al. 2021 JAE](https://doi.org/10.1111/1365-2664.13961) の2014/2017年原Dryadを用い、対応する鉄道側とInterior側の群集を**同じ31地点で比較**した。v315の結果を見た後に設計した探索的補足であり、事前仮説Aを独立地域で確証的に検証したことにはならない。

## 結論

**2014年の原31地点では、「標高が高いほど鉄道群集が周囲より温度親和性の高い種に偏る」予測は支持されない。** Tichý指標（1–12）では標高100mあたり差が+0.0573だが、station / between-station層内の標高を4,999回入れ替えた主診断で正方向上側順位0.321。より広い分類群を持つEIVE（0–10）ではむしろ−0.0825/100mと**逆方向**で、主予測の正方向順位0.899。これは「差の不存在の証明」でも、標高/微気候の因果効果でもない。2指標は同じ生態学的独立反復ではなく、尺度も異なる。

**鉄道とInteriorの「平均温度親和性」は全31地点ではともに小さい正方向**だが、標高に対する**変化方向は定義によって異なる**。元サイトの標高に対するTichý単純相関は0.094、EIVEは−0.246で、同じ地点に現れる種の構成による指標差を無視できない。

## 1. 真正元資料、標高、対応デザイン

- 元公開[Dryad version 99735](https://datadryad.org/api/v2/versions/99735/download) の `Matrix_plot.xlsx` を新規に取得し、元XLSX SHA256 `529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474`を確認。元248行＝31物理地点×2014/2017年×4区画、植物123種列。原著にある4つの空白セルは**欠損**として扱い0/不在にはしない。
- 原XLSXの最初の6列は `Name of the Site, Latitude, Longitude, Altitude, Year of sampling, Location`。**31地点すべてのAltitude列は248行で数値かつ同じ地点で年・区画にわたり一致**。範囲 **1,547～1,770m**。2025年の駅標高リストや別の文献の標高を代入していない。この値は元原表そのものであり、原著本文の概略標高帯と同一に丸め直していない。
- 各元地点・同一年にTrack(100m²)＋Embankment(100m²)の**種集合の和**と、Interior Plot 1(100m²)＋Interior Plot 2(100m²)の和を比較。種の被度は重みに使わず、各側で温度指標を数値として持つ種を**等重み**にして平均。両側各3分類群以上でなければ結果を出さない。
- original-source strict species matching。元ラベルがagg等で一意に同定できない種については、**全サイト・両年・両生息地へ同一の利用不可マスク**。別の区画や年の観測を種として推測補完しない。
- 主指標Tichýは[Zenodo fixed v2](https://doi.org/10.5281/zenodo.7427088)、EIVEは[fixed 1.0](https://doi.org/10.5281/zenodo.7534792)、それぞれ元Excel SHAを固定して再取得。Tichýの**温度不関 `x`**を0、NA、中央値には置き換えていない。形質指標の1単位は1°Cではない。
- 元16駅だけのv315駅等重み平均Tichý `+0.0026537873998`、EIVE `+0.0600416270751`を原ソースから完全再現。今回の31地点の平均と同じ数になる必要はない。

## 3. 2017再調査は同じ地点、独立データの追加ではない

原2017年の4個の植物セル欠測を含む区画について地点の不在としなかったため、**2017年の比較は27元地点（駅15、駅間12）**。原標高との傾きはTichý **+0.153227/100m**（配置の正方向順位0.2104）、EIVE **+0.011152/100m**（0.4608）。この年に指標体系間の傾き符号は揃うが、いずれも診断分布で極端でない。2014から2017への**同一27地点**での対応差の変化の標高傾きはTichý+0.090604（0.3428）、EIVE+0.093743（0.1714）。これも独立地域や列車輸送の時間的因果を示さない。

元Kashmir2014/2017は著者自身が季節・標高×在来外来種数の差を解析した研究であり、ここでの追加は**原同地点における熱親和性指標の鉄道内外の差の傾き**だけである。新しい操業貨物本数、草刈り、実種子散布や地点微気候を測ったものではない。

## 4. 帰無・推論の範囲

主解析の31元地点は鉄道の一つの山岳回廊に沿う。駅と駅間の二層内での4,999回の標高入替は、`ΔT ~ original_altitude/100m + station_vs_between`の主係数に対する**技術的な条件付き順位**。標高が線路方向の座標、土地利用や湿潤度、バラストの高さなどと共変し、地点間に空間依存があるので、厳密な因果的ランダム化p値とも一般生態学的な独立反復p値とも扱わない。site LOOは一駅の全4区画を一度に除外し、区画を別サイトに数えない。

気温指標が正でも列車の熱による生理的な越冬、暖地種の標高方向への定着、個体群の繁殖、生息地置換、列車による種子移動を示さない。今回の**正と負の異なる主指標の符号**は、PR45の気候依存仮説Aを「この一回廊で裏付けられた」と書かない理由になる。地域間比較Aを実施するには、異なる気候帯に**2つ以上の独立した同年・同面積・近接非鉄道対照付き回廊**が不可欠。
