# v6.6 frozen public original-GBIF France Burgundy 50km source-event quality protocol

Frozen after the v6.5 raw ALL-PLANT Parquet source file selection, **before examining any French GRIIS introduced plant event or railway association**. This is a source-only, noncausal ecological feasibility check.

**Independent source lineage:**
1. [Official GBIF Oct 19, 2026 publication](https://data-blog.gbif.org/post/extending-parquet-snapshots/) identifies the August 1, 2026 experimental Darwin-Core-equivalent GBIF original Parquet, underlying download DOI **10.15468/dl.8yrbe7**. The development preview is **not** a separately issued DOI download.
2. [v6.5 actual bounded source-object audit](https://github.com/zuizui0223/tetsu/actions/runs/42959420881) found **671,528** 2018–25 ALL Plantae source rows in the original Burgundy 200km bounding envelope, among 15 positive (33 zero) scanned objects; 71 candidate objects were found in the original source-centroid partitions and **23 were not scanned**. More than 400 MB files were omitted by the original source search, and A5 r2 selection used original 50km cell centroids, not a polygon-complete partition covering. Thus the data do **not** give a complete French plant census.
3. [v6.3 real official six-country GRIIS Backbone2023→COL26.5 XR crosswalk](https://github.com/zuizui0223/tetsu/actions/runs/42844630098) found for France **1,618** old GRIIS listed accepted GBIF species keys, 1,064 primary direct accepted COL concepts and another 145 synonym-resolved old taxon keys. **409 are not mapped/usable**; they are UNKNOWN, not plant absence. The crosswalk is May2026 COL26.5; the August2026 GBIF development preview taxonomy may be different.

**Fixed current test and strict limits:**
- Geographic frame is the original v2.9 **France Burgundy** 4×4 EPSG:6933 50×50 km cells (16 × 2,500 km²); country FR, source years 2010–2017 and 2018–2025.
- All source files scanned and verified in v6.5 for their true all-plant France 2018–25 source rows are the maximum source universe. Files with ZERO all-plant rows in the same country+period+BBOX can be skipped by deterministic source-geometry pruning, but remain disclosed as source zeros, not plant absence. Source object keys are selected before checking GRIIS membership or any physical rail/road association. No new object selection by presence of a desired taxon.
- Parse original interpreted events from these files for 2010–2025 via bounded streaming DuckDB; validate 2018–25 all-Plantae source bounding-envelope count against the independently verified **671,528** from v6.5 before interpreting GRIIS findings. The geographic result in 2010–17 can be described but the 48-file selection was validated on late-period rows, so earlier completeness is especially unsupported.
- The primary GRIIS introduced key crosswalk is **strict COL accepted/provisionally accepted Plantae species**, not old numeric GBIF keys. An explicitly labeled **secondary** result includes mapped accepted IDs for synonym-resolved old GRIIS names. Never convert unmatched or ambiguous names into native or absent classifications.
- Keep only GBIF original PRESENT/DETECTED rows, country FR, interpreted species rank, source-frozen cell polygons and original years. Source GBIF records outside these exact cells are not biological nonpresences. No single source file is claimed representative of the full official GBIF archive.
- Identify and de-duplicate exact GBIF ID, dataset+occurrenceID and (when a genuine eventID exists) dataset+eventID+eventDate+species+cell. Where eventID is absent, retain individual GBIF events without inventing observer-based pseudo-events. The duplicate source category is not a repeated ecological survey guarantee.
- Strict coordinate source quality is known coordinateUncertaintyInMeters **>0 and ≤5,000 m**, with secondary known **≤25,000 m** and unknown uncertainty listed separately. Missing uncertainty is not assumed spatially precise.
- Return only aggregates by 50km cell×period, never raw GBIF record IDs, human observer names, eventID, or precise event coordinates. Files are public but individual occurrence privacy/attribution must still be respected.
- Report source event counts and cell count meeting exploratory ≥5 GRIIS accepted categories + ≥20 distinct event–species counts; any missing-source cell is **NOT** an ecological absence. No train-mediated propagule claim or significance test from this source audit.

**Why this still is not a macro ecological transport test:** the input is a bounded source sample from an experimental GBIF snapshot, and all railroad routes are mapped physical 2026 infrastructure. It does not include active freight services, field seed traps, railway verge surveys, observer-level field sampling, or a country/biome-random sample. Before any physical rail vs flora correlation, completeness must be proven in each original geographic cell (ALL relevant A5 partitions and files) or an actual GBIF DOI-bearing download must be analyzed.
