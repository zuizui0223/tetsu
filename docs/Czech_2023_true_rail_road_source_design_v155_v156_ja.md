# 鉄 v15.5–v15.6：チェコ実駅×真の歴史的鉄道・道路網の独立反証（設計凍結）

更新：2026-11-15。**この記録は2023年チェコ全国OSM 816MB PBFの原本ソース実行が成功する前に作成された事前の設計記録。未成功の生物学的実測係数を記載しない。**

## もとデータの規模と不均一な観測単位

- 元植物調査：Kutlvašr et al. (2024), Preslia DOI 10.23855/preslia.2024.247。2020–22年39実駅、5元路線区間、元の3微生育地を合算した駅単位のS1で761現出現分類群、6,941出現欄。Pladias散布戦略＋Raunkiaer生活形の双方が元の公表分類群名に厳密照合できた544分類群/5,081出現。
- [v15.3本物の駅名×座標照合](Czech_original_39station_SR70_geography_falsification_v153_v154_ja.md)で、独立の2026年チェコ鉄道公式SR70由来駅代表点に、原著39駅中35駅のみが名義上厳密一致。Děčín、Kutná Hora、Nymburk、Pardubiceの4原著駅位置は未特定のまま。**35駅は2020–22年に植物を実際に調査した区画の中心ではなく駅の2026年代表座標**である。
- ソース予定：Geofabrik、チェコ全土2023-01-01歴史版 https://download.geofabrik.de/europe/czech-republic-230101.osm.pbf 、ダウンロード公開予定サイズ816,159,635 bytes。**ファイルのSHA256は真正取得が成功したActionで値を確認するまで「固定済み」と呼ばない**。
- 原著5路線区間・35駅・最大595依存駅ペア、国は**一つ**。スロベニアの89地点100m調査区とは観察方法、植生範囲、元の生活史と形質ラベル、調査時期が違うため、原データを一つのメタ生物効果量としてプールしない。

## v15.5 本物のOSM physical rail/road graph source quality gate

同一固定日時の公開国土OSM Wayを実際のnode IDでつなぎ、同じ線路/道路が交差していても元ノードIDを共有しない物理立体交差をつながない。対象鉄道=rail/narrow_gauge（非現役・工事の明示タグを適宜除外）。対象道路=drivable主要道路・連絡道・住宅地・サービス道。元OSM node間測地線距離の無向最短経路。路線の実運行状態、貨物発着地、実際の車両や種子の向きは一切自動的には確定しない。車両が走れない可能性がある新旧線路や各駅の構内通行許可も不確かである。

**元のスロベニア検証で凍結された**植物地点から最寄り鉄道OSM物理ノード ≤0.50km、道路ノード ≤2.00km、独立の2つの駅代表点間の測地線距離 ≥2km。両経路がともに存在するときだけrail/road shortest path比を計算。切断経路をゼロ植生、無限大の輸送抵抗や未出現種と見做さない。全国単位の抽出なのでオーストリア/ポーランド/スロバキア/ドイツへ通じ戻る経路はクリップされる可能性がある。経路が測地線距離の8倍＋4kmより長いペアを主解析から除外（事前基準、posthocな符号選別なし）。全経路接続性・スナップ・欠損を先に報告。

## v15.6 5元区間留保による真正種同一性の道路比較

最大595のペアの実原表Jaccardを、スロベニアの「同一路線で種が似る」という観察とは異なり、**実際の鉄道距離と道路距離の同時条件付け**で再検証する。3モデルの説明変数は次のとおり、ridge alpha固定10。データ数の事前の「モデル推定可」条件は道路・鉄道両方の実経路が存在する250以上の駅ペア／元35駅中30駅以上／5元区間中4区間以上。

| 計算する原著モデル | 固定する説明変数 |
|---|---|
| M0 | log測地線距離、4粗機能群重複、同原著区間指標、S2元駅面積のlog平均とlog差、元種数log平均と差、鉄道・道路への実際のGISスナップ距離、スロベニアから継承した固定地理区分と形質群区分 |
| M1 | M0＋**真の2023 OSM道路ノード網の最短経路距離log** |
| M2 | M1＋**真の2023 OSM鉄道最短経路距離÷道路最短経路距離のlog比** |

元の路線区間を1区間ずつ完全にholdoutし、含まれる元駅が関わるすべての種共有ペアをテストへ置き、残る駅ペアからモデルを学習する。元区間外予測JaccardのMSEを比較し、**M2がM1より低い方が鉄道経路の追加予測利得あり**と定義。最大5区間しかないので独立国間の統計的有意性は示さない。原著S1の元観測で形質双方既知544分類群が主軸、全761元観測分類群は別の感度軸。形質欠損を「非風散布・非在来種」に無条件置換しない。

*発生学・進化学に対する限界*：元の実駅種共有が同じでも、鉄道を通って種子が輸送されたか、各駅土壌で定着しやすいか、以前からその地域に分布していたか、草刈りや強風に対する可塑的または遺伝的適応かは元の横断植物群集から分離できない。貨物列車種子捕捉や特定の管理実験が別途必要。

## 結果ゲートと再現

1. 2023歴史的OSM PBF完全原本を取得・サイズ・SHA256照合し、35駅の鉄道・道路スナップと物理経路を実際に計算したら、原著駅ごとの実経路と国境切断の影響を確かめる。
2. 道路・鉄道両方の経路を得られない駅ペアが多く、少なくとも4区間/30駅/250ペアの事前支援条件に達しなければ、**効果は不識別**。効果量ゼロとも負とも書かない。
3. M2がM1のholdout MSEを悪化させる場合、チェコ元研究でも鉄道経路の独立した追加予測利得なしとする。改善しても、2026駅代表点と元調査地のズレ・実際の貨物運行データ不足・地域種プール差があるため、種子運搬を示す因果効果としない。
4. スロベニアとチェコで出るMSE改善率は**予測利得の診断値**として報告できるが、似ている数字だからといって同じ生物の列車散布率を意味せず、異種の応答/条件付け/地点粒度を1つの研究数に重複しない。
