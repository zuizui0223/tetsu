# v340 凍結プロトコル：ギョウギシバの2014→2017再記録は軌道と内陸で異なるか（2026-11-24）

**開始時点:** v339/v339bがカシミールの温度指標のC4差の大部分は `Cynodon dactylon` に敏感であることを見た後に立案した**事後・探索的**な検定。今回の年別・区画別の **Cynodon 同一地点再記録集計を見る前に**以下の比較・指標・帰無を固定する。

## 真正データ
Rashid et al. 2021 DOI `10.1111/1365-2664.13961` の公開Dryad v99735 `Matrix_plot.xlsx`（SHA256 `529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474`）。2014・2017年×同一31地点×4区画。原著の源植物種ごとの定量値は `species abundance` と表現されるがセルの物理単位は未特定。元種×plotの個票、元plot GPS・site IDは出力しない。欠測が1つでもある `site×year×zone` は原v254解析と同様、未完備扱いで**0出現へ変換しない**。

## 主問い
1. `Cynodon dactylon` の2014出現→2017同一地点同一区画再記録率は、軌道（Track）と遠い内陸（Interior Plot 2）で異なるか。
2. 31元地点のうち **両年・両区画が完全観測** された共通地点だけで、`Track` と `Interior Plot 2` の占有地点割合が2014→2017でどう変わったか（zone×year DIDを1個のsite単位で評価）。2014で出現していなかった地点の2017初記録も分解する。
3. 2014・2017の**両方で記録された同じ種・同じsite×zone**に限り、原著 positive abundance 数値のlog比 `ln(A17/A14)`・原著数値の絶対増減を要約。未記録を0のabundance測定とは呼ばない。

## 共通母数と集計
- 主解析は`Track` と `Interior Plot 2` の両年とも欠測のない元地点のみ。「両年同一地点・同一区画」の比較。**駅（16）と駅間（15）の区別は原source名で先に固定**し、siteを繰り返し使わない。
- 各zoneの2×2遷移表 = 2014/2017 (0→0、0→1、1→0、1→1)。再記録率 = 1→1 / (1→0+1→1)；新規記録率 = 0→1 / (0→0+0→1)。
- 2×2で両zoneとも2014に出現したsiteの2017再記録を比較する**厳格共通ベースライン感度**も報告。片zoneのみ2014に出たsiteはゾーン差の再記録率を同一個体のように引かない。
- 図を念頭に置いた元31site×zoneの`Cynodon`全体、駅/駅間、`C4（Cynodonを除く9候補）`、`C3イネ科6候補`（各群の「群に1種以上出現したか」）を別々に示す。複数種群は種自体が違うので **同一種の生存** と解釈しない。
- Source abundanceは出現の両年陽性値を厳密に条件とする。2014 positive種の2017非記録は `observed absence` であって数値0による密度変化として算入しない。
- ランダム化試験ではないため、site単位の `[Track(2017−2014)]−[Interior2(2017−2014)]` のラベル符号反転は**記述的帰無診断**（19,999 Monte-Carlo draws +1, seed340）とし野外独立p値とは呼ばない。サイト単位のペアbootstrap percentile (4,999 draws, seed341)を技術的区間と呼ぶ。駅/駅間差は交絡の強い探索のみ。
- 近い `Interior Plot 1` を距離感度として別パネルに残す。主結果と真に独立な地点ではない。 `Embankment` も元source要約可能だが今回の主解析外。

## 停止判断
- (a) 軌道の2014占有地点が内陸より多く、2017では**同一地点再記録率が軌道側で低い**／または軌道優位の占有率が大きく低下するなら、「検出される機会と継続が乖離する」観察的候補として次段へ。ただし**真の定着失敗、外部からの反復補充、列車散布は結論しない**。
- (b) 同地点再記録率が軌道同等以上なら「軌道では一過性」という仮説は支持されない。
- (c) strict共通2014陽性サイトが僅少（5未満）または2014片zoneにしか陽性でない場合、直接的なTrack/Interior persistenceのzone比較を止め、2×2表と縦断占有差のみ報告。
- (d) ほかのC4候補群やC3イネ科が正反対なら、ギョウギシバ固有効果として分類し、C4機能群の普遍則に広げない。

## 主な限界
- 3年後の同じ地点での記録は個体生存・繁殖成功・定着・移動源を区別できない。
- 調査努力・季節・植物相の検出可能性・管理介入・撹乱・強風・除草・2014/2017の天候は原因として識別されない。
- 駅・駅間は鉄道本数の操作ではない。原著一研究31地点のみで全球的な外的妥当性はない。
- v339研究ブランチ上に積み重ね、mainや既存結果を変更しない。
