# v305 鉄道交通・都市化・植物群集の結び付き：解析前仕様

2026-11-20。既存のv274–284の結果は既知。本仕様は新しい都市化との結合と調整結果を見る前に記録する探索解析計画であり、独立した事前登録ではない。

## 目標と推定対象

都市化を考慮しても、鉄道交通量または公式幹線／地域線区分が、(A) 同地点の道床肩BSと法尻BTの種共有、(B) 離れた鉄道地点どうしの種共有と異なる関連を示すか。BSとBTはともに鉄道内であり、BTを非鉄道の周辺対照とは呼ばない。地点間の結果も駅間そのものではなく100m鉄道調査区間間の結果である。

## データ・説明変数

- Slovenia原著89地点15線区・2022/23年。既存SHA検証を通した原XLSXからBS/BT種集合・GPS・調査年・単複線を再抽出。左右は地点内で統合。
- 公式G/Rは法的幹線区分であり実交通量ではない。実交通量は既存の両端駅距離標によるEurostat2020対応を再利用し、27地点9物理交通区間5線区。未対応地点を0本にしない。2015年は取得可能なら感度解析であり独立再現ではない。
- 都市化はESA WorldCover2021 v200の半径1km内built-up面積割合を主指標、500mを感度。cropland/tree割合は交絡状況の記述に使用。都市化の二分閾値を結果に合わせて作らない。分類可能面積95%未満は欠損。都市化は土壌・刈取り・風圧の実測代替にはならない。

## A 局所共有

主応答はv275と同じ、線区内のBT種頻度と地点種数を保存した帰無のJaccard非類似度－実測非類似度。正は同地点のBS/BT共有の超過。帰無は全89地点で構築し、交通対応地点だけで作らない。元99drawを再現し、より多いdrawで感度を確認する。

1. G/R比較：全支持地点で、説明変数G/R、都市化、調査年、単複線を使用。各線区の合計重みを等しくする。単線のみを事前指定感度とし、線区1本除外で符号と効果幅を確認。都市化のG/R共通範囲内での比較も示す。
2. 実交通量比較：9物理交通区間へ応答と都市化を平均化。各区間1票、log(1+年間貨物列車数)＋都市化を主モデル、旅客は別モデル。小標本なので多数の共変量を同時投入しない。線区固定効果＋都市化の仕様は行列rank、残差自由度、条件数を明示し、残差自由度<3なら推定可能性監査のみ。区間・線区1個除外で安定性を報告。
3. 帰無補正前のJaccard類似度も併記し、帰無の選び方に依存するか区別する。MCMC drawを野外標本として数えない。

## B 地点間共有と空間範囲

- BS、BT、BS∪BTを別々に扱う。主対象はBS、他を感度とする。
- 直線距離帯0–5、5–20、20–50、50km超を固定し、G/G、R/R、G/Rで平均類似性を記述。ペア数を独立標本数としない。線区対を集計単位とした値と、その支持地点・線区数を出す。少数支持域から到達距離を断定しない。
- 距離と都市化をそろえる比較は、アンカーから同一路線と異路線の候補への距離差≤2.5km、最大40km、候補間built-up差≤0.05、同調査年・同単複線。種組成を見て候補選択しない。既存v280の地理のみ／年・単複線一致を併記し、サンプル変化と調整を混同しない。最低12アンカー4線区未満は未識別。
- 実交通量と地点間類似性の比較は交通区間間を単位とする探索記述。実接続ODは未取得。同一路線を列車の実往来の証明としない。

## 判定と成果

主要な確認対象は方向、効果量、支持域、除外感度であり有意な仕様だけ選ばない。都市化調整後の符号保持を因果の証明としない。土壌、草刈り、同時年の交通、非鉄道対照を調整できない場合は明記する。
