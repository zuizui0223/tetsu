# v341 prespecified post-v340: do warmer-temperature-indicator species fail to be recorded again at railway plots?

Freeze after seeing v340 Cynodon repeat-occupancy results; **before** inspecting any EIVE trait association with species-specific re-recording. This is exploratory, not a preregistered causal test.

- Original source Rashid et al. 2021 Dryad v99735 `Matrix_plot.xlsx` SHA256 `529f3b97521933018e12623b61f531f012c67241cae2602a6675dbd534192474`, independent EIVE1.0 SM08 MD5 `0f0ce19cd2a781eeed027d8b0acadbcb`. Repeated survey 2014 and 2017 same original 31 railway sites×4 zones; both years Track and Interior Plot 2 source-complete 28 common sites (verify exact count). No missing as observed absence, no source site IDs/plot x species exported.
- For each **2014 observed** EIVE-matched species in each site and zone, label `2017 same site same zone re-recorded?`. Species with a 2014 recorded positive and no recorded 2017 positive are observational losses, NOT mortality. This conditions on 2014 presence, avoiding confounding by 2017-new-record taxa.
- Freeze primary EIVE coverage gate `systems>=3`, sensitivity `systems>=1`. Freeze Track vs Interior Plot 2 (near Interior Plot 1 is separately reported sensitivity only if feasible). Record EIVE-matched 2014 species/year/zone counts and 2017 re-observation by zone; report each site's trait support numbers.
- Primary within-site statistic for each source site/zone where 2014 has at least one 2017 re-recorded and one not re-recorded EIVE-matched species: **mean EIVE thermal position (2017 recorded taxa) minus mean EIVE thermal position (2017 not re-recorded taxa)**. A negative contrast indicates warmer 2014 taxa were less likely to be recorded again *within the same original plot*. This does not prove population extirpation. Take mean across original sites; report n eligible, all-site sign directions.
- Among **identical source sites where both Track and Interior2 have informative retained/lost 2014 species**, compute site-wise Track minus Interior2 difference in the thermal survival-alignment. Null diagnostic: 1999 globally fixed per-species EIVE labels shuffled across only EIVE-eligible source taxa (not each site independently), two-sided centered on permutation mean, seed341; also 1999 restricted within-genus trait-label shuffles, but report count movable source taxa and potential low power. Site bootstrap of eligible matched plot-pair differences 1999 draws, report percentiles as technical spatial-duplicate sensitivity not independent causal confidence intervals. No post-hoc threshold tuning.
- **Remove Cynodon only** and **remove all 10 provisional C4 candidates** from the 2014 taxa in both zones and both years without changing common source sites; retained/lost-support may become insufficient in a source plot; report number lost and re-compute. Same EIVE≥3 primary then ≥1 sensitivity.
- Initial 2014 species source-abundance may affect re-observation. For each site/zone with retained and non-reobserved taxa, report the difference in mean log(2014 positive source abundance) between retained and lost. This is an independent confounding *diagnostic*, not an adjusted regression or a metric of actual species biomass.
- **Stop mechanism claim** if Track-vs-Interior thermal persistence contrast is not distinct from null or disappears after Cynodon/C4 removal, or if too few shared informative site pairs (N<10). Even if supported, an EIVE association is not observed thermal mortality, local recruitment, propagule input, train dispersal, selection or ecological mechanism proof; a second independent rail dataset and local temperature microclimate are necessary.
- Original Rashid et al. 2021 authors already interpreted general 2014–2017 species redistribution as post-construction succession; do not represent this broad phenomenon as a newly discovered temporal pattern.
