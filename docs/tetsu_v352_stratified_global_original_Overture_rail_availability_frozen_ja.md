## Actual source verification
- Use official [Overture Maps 2026-11-18.0 global transportation segments](https://docs.overturemaps.org/guides/transportation/) via Python Overture public STAC/GeoParquet client `record_batch_reader("segment",bbox=...)`; actual latest STAC version verified by source-run metadata. Pinned source schema `subtype=rail`, `class in {standard_gauge,narrow_gauge,unknown}`, exclude tunnel, bridge, disused, abandoned, construction, covered, rail service where applicable. No fabricated active traffic observation.
- Source bbox is WGS84 envelope of four source EPSG:6933 cell corners, with a small precision margin; actual `geometry` WKB clipped to **exact original 100km×100km EPSG:6933 cell square**, so nearby track crossing the bbox outside the cell is never counted as in the cell. Clip length measured geodesically (WGS84) in km. Stream Arrow record batches and filter subtype rail before materializing railway rows; cap per-cell total source transport features and explicitly fail as unavailable if the source cannot be read completely. A source cell with complete original scan and zero eligible railway km is a **true mapped-rail-absent for this definition**, not a zero biological species effect. Record source error types and negative support explicitly.
- Optional iNaturalist source **counts only** in WGS84 bounding rectangle of sampled 100km cell, original 2025 wild Plantae research-grade with per_page=1; do not fetch or publish original individual plant records, observer identifiers or exact coordinates. This is a source-data opportunity indicator only; iNat bbox count is NOT inside the projected cell, and not a rail-near/baseline comparison.
- Original 2026 rail tracks are time-shifted from original 2025 plant records. Unknown class is a conservative mapping category but not proof of actual train activity. Excluding bridges/tunnels can underestimate urban rail length and some dense sources might be covered.
- Original v351 sample coordinates are public 100km cell **centroids**, not sensitive original species records. Source raw Overture geometry and rail point IDs are never redistributed; store only six source cell identifiers/hash, original population pi, clipped source rail count/km, source completeness/error, source climate band, original API observation-count opportunities.
- Scientific result gate: **no** generalization about global railway warm species / causal selection or rail-network length if the worldwide railway km denominator is unknown. Even six genuine rail-positive source cells do NOT equal six independent biological population surveys. This pilot is the first original rail *source availability* test of a design-based land-grid sample.
