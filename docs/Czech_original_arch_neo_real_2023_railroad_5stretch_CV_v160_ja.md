# 鉄 v16.0：チェコ真正鉄道・道路網で考古帰化植物と新帰化植物の種共有予測を直接比較（2026-11-15）

## 元データ・コホートと新しい検証の位置

元植物調査：Kutlvašr et al. (2024), *Preslia* 96:247–266, DOI https://doi.org/10.23855/preslia.2024.247。著者が2020–22年にチェコの39鉄道駅で現地調査。著者原S1と訂正S2、Pladias正規形質、公式SR70台帳の第三者2026年駅**代表点**を厳密駅名一致35駅に結合したデータ。**原著植物区画の実GPSとは異なる**。

鉄道・道路網：Geofabrik Czech Republic **2023-01-01の本物の816,159,635 bytes OSM PBF**、元SHA256 26ff09ded5fa72dc9556b543b532d7df011f2e3c08af461ea2f537a9b0b42747。Wayの実OSM node ID接続だけを使い、立体交差を架空に連結しない。これは物理的最短経路であり、**貨物列車の実運行経路・輸送量・実際の植物の種子散布ではない**。

**[真正元生物原著＋外部元OSMデータ、完全年別元MSE検算・5元路線区間留保 SUCCESS #43685982738](https://github.com/zuizui0223/tetsu/actions/runs/43685982738)**。v15.6から事前固定された同じ35原著駅・594の依存する駅ペアを全群で厳密に保持（595ペアのうち2km未満1ペアを元から除外）。元の544形質既知分類群と761現在出現全分類群のv15.6元sourceのMSEを**同じ原本からそのまま厳密再現しなければ**群別効果は一切出さない検算ゲートを成功。

v15.7〜v15.9の群別結果を既に見た後の**事後的探索解析**。考古帰化植物と新帰化植物が同じ駅で検出されたことと実際の到着年代・列車散布能力が等しいことを混同しない。原著のarch（古くからの帰化種）151分類群／元駅×種1,763件、neo（新帰化種）150分類群／929件、明示的外来植物全301種／2,692件。原著のタグのない植物を在来種と勝手に扱わない。

## 元の鉄道・道路の距離と2つの種数調整方法

M0：元駅間の直線距離、元4機能群（生活形×元の散布戦略）、元駅面積と種数、同元鉄道路線区間、鉄道/道路OSM実ノードへの最近接距離、前の原著に固定した地理/機能区分。M1：M0＋実道路最短経路距離。M2：M1＋log(2023実鉄道最短経路／実道路最短経路)。ridge α=10固定、原著5元区間を各1区間ずつ丸ごとテストに除き、残り4区間の元駅ペアで学習する。統計単位は原著35駅とネストした5元路線区間であり、594ペアは594の独立実験ではない。

植物群ごとの種数（log1p）で調整する場合と、元全形質既知植物相の種数（元v15.6）で調整する場合を分けた。どちらの解析でも**対象の駅ペア・地理・形質群・道路/鉄道距離は全く同じ**。各群の組成Jaccardが違い、元駅ごとの種数や出現頻度も大きく違うので、群間のβやMSEの絶対値を種子運搬率・繁殖確率として比較できない。

### 元の真正生物学データでの結果

以下は「道路も含めたM1に鉄道距離を追加したM2で元5区間の等重み予測MSEが何%改善するか」。プラスが改善、マイナスが悪化。

| 原著の元植物群（原著源種×駅） | 群ごとの元種数で調整したMSE改善率 | 全形質既知植物の元種数で調整した感度 | 群ごとの元種数調整で改善した元区間 |
|---|---:|---:|---:|
| 考古帰化植物 151分類群 / 1,763件 | **−1.489814%** | **−4.320971%** | **2/5** |
| 新帰化植物 150分類群 / 929件 | **+0.868382%** | **−0.040482%** | **3/5** |
| arch＋neoの明示的外来植物全301分類群 / 2,692件 | **+0.121713%** | **−2.156642%** | **3/5** |

元新帰化植物の群ごとの種数調整モデルは、M0=**0.005423269**、M1=**0.005439556**、M2=**0.005392320**で、元鉄道追加による改善は微小。全植物種数で調整すると、M1=**0.007860739**、M2=**0.007863922**で**改善が消える**。元考古帰化植物では群ごとの種数調整でもM1=**0.005609320**→M2=**0.005692888**と悪化。全外来植物群では群ごとの種数調整でM1=**0.003787861**→M2=**0.003783250**とほぼ同等だが、全種数調整ではM1=**0.004184040**→M2=**0.004274275**と悪化。

この「新帰化植物には鉄道の相対距離が追加の種共有予測に効くかもしれない」という見方は検証に値する一方、**元35駅、わずか5元区間、群あたり30程度の元地点種数と異なる出現頻度、調整法で符号が動く事後探索**に依存する。2つの群がそれぞれ独立に元35駅×5路線から採れたわけでもないため、真の「新旧群間の散布率差」や鉄道輸送適応の肯定的結論として格上げしない。

## より大きな研究課題へつなぐ

**A 真の種子到着**：列車から捕捉された穀粒や実際の積載・脱落量を同じ鉄道OD経路と結ぶ。今回の原著では種子移送を撮影・捕捉していない。

**B 地理的種共有**：条件付き鉄道距離の種共有に、地域種プール・道路距離・植生サンプル機会の相関が加わる。新帰化植物の微小予測利得は、独立の研究・駅への真の原著GPS・実列車輸送量を使う前向き検証対象として位置づける。

**D 管理・ストレスフィルター**：フランスRATPの2m²固定面積394群集区＋職員除草要請170件を使えば、線路・法面の機能群の違いの別系列で比較可能性があるが、実際にどの区画をいつ刈ったかは未取得。原著平均だけでは管理に対する可塑性や局所適応の選択係数は推定しない。[管理要請と植物群集原著の精査](RATP2025_original_track_vs_embankment_staff_ALERT_evidence_v161_ja.md)。

**C 可塑性と進化**：元の鉄道種群集中に多年草と一年草が異なる比率で出現しても、同種の遺伝的草刈り耐性・列車強風の適応ではない。遺伝・共通栽培/相互移植・実際の刈取時間の動態が必要。

本研究は一か国・一原著内の派生層別解析。研究台帳17文献・元群集行列を本物として取得した2原著の件数は変えない。メタ解析の3効果にしない。
