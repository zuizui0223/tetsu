# Rail-focused disturbance and movement trait program

User asks for actual railway-relevant traits, not a generic cross-taxon association. Main comparison mapped active versus mapped abandoned/disused railway; operation status is not randomized closure, nor known management intensity. Keep three competing processes distinct: (1) recurrent management/disturbance filters life histories; (2) physical transport/connectivity selects dispersal traits; (3) open habitat and vegetation structure select habitat/food guilds. No claim that plant stature or wing size measures wind tolerance directly, no claim all railways are mown or have equal train airflow.

Prior localized original Slovenian field reanalysis: ballast shoulder vs toe strict annual fraction +.054703, strict wind-diaspore fraction -.050740; negative wind contrast persisted within life-history strata (v106). Mean log height difference weak, width not compressed (v224). These comparisons are not active-vs-inactive and not global. Prior global growthform woodiness coverage was 19.51% species; primary active-minus-inactive woodiness unsupported; avoid repeating that as annuality. Prior AVONET HWI low-vs-high unadjusted status contrast recurred but independent habitat/migration-conditioned wing mechanism failed; do not reopen by slicing same windows. See historical decision.
