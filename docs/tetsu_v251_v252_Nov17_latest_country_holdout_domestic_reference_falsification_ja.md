## 4. 論文の現段階の適切な結論・今後の識別実験

**現在肯定できる**：鉄道駅の種別出現順位には別の欧州調査でもある程度保存される群がある。既存CZ39→他国内種頻度の順位相関はIT+0.392、HR/BA+0.257、SI+0.512、SK+0.568。カシミール原2014線路側への共有種順位は弱く、地理と生息地が違うと必ずしも普遍的でない。既存3原著＋スロベニアのCWM内部固定頻度の地理区別帰無は正（+0.039〜+0.075）だが、新東SK19原著は−0.0023とほぼ零。**人工同型の鉄道環境で必ず分化する／必ず収束する**という単純な二択は全研究で支持されない。

**現状の未識別**：国内一般的攪乱群集よりも鉄道**だけ**を好む種が同じ地域・同じ季節・同じ原採録努力で繰り返し出現すること。鉄道網の発車頻度・上下列車本数は鉄道間種子共有や遺伝適応を示さない。

**次の最優先実証**は、
1. **地理・標高・都市化・採集年・同面積のlocal domestic control**を固定し、他国鉄道と都市／道路／空き地／河原の適合頻度の順位を競わせる。国内対照の比較種集合は全参照型で固定する。対照を選ぶ段階で対象鉄道の種名や形質を見ない。
2. 同じ駅のtrackbed／embankment／interiorが同年同法で撮られた**Kashmir31地点×4ゾーン×2014,2017の真正Dryad**を一番強い非欧州ケースとして、種数差と2D形質欠測を分ける。2017年のTrackの2D LE DA coverageが乏しいので、「2014のCWM距離差が2017にも再現した」などと言わない。2014年Track−Interior Plot2のshape距離は元12駅で**+0.05075**、種数等化後**−0.01729**と方向が変わる。種名Jaccard非類似度の全16駅差は2014年**−0.00512**、2017年**−0.04721**（稀薄化後それぞれ−0.05813、−0.13206）だが、群集plotを共有する年の記述的比較である。
3. 中国–ラオス鉄道14駅/84調査区等で**鉄道と対照の個別種×区画行列**を取得して、非欧州の標準化実証を増やす。公開出典の存在と実際に元生物行列が検証済みかを区別する。
4. 全球山岳MIREN roadsを**鉄道の独立研究数に含めず**、道路回廊の別の機構対照として保持。強い2D trait coverage ≥50%、10種以上では5地域192siteが残り、roadside CWM距離差は内陸より負だが源地域CODE数と植物地理偏りが大きい。国内同国の道路は真の同地域駅対照とは限らない。
5. 列車による実種子輸送、管理・刈取り・風による適応選択を実証するには生体移動・実際のsource OD・繁殖成功・原個体の形質や遺伝変異が必要。種名の頻度順位や種代表の草丈・種子重はその直接証拠ではない。
