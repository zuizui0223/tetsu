# v341 凍結設計：CzechVeg-Open 2026年版で真正鉄道区画と近傍植生区画を結合する

**作成：2026-11-24。これは新規独立データの探索・再解析であり、アウトカムが既知の確認的試験ではない。**

## 真正ソース
- Czech Vegetation Database v1.1、DOI `10.5281/zenodo.19231152`。全117,739調査区の元ヘッダー `CzechVeg-Open_headers_v1-1_2026-03-26.csv`（MD5 `0bc920462d1f9eac473e7b2a231e6782`）。元植生種×調査区 `CzechVeg_Open_species_v1-1_2026-03-26.csv`（MD5 `b296e5e19f03fb3bad0a8347c317f8a3`）、`RELEVE_NR`で結合。元調査の面積`SURF_AREA`、緯経度`DEG_LAT/LON`、位置精度`PRECISION`、出典`REFERENCE`、調査年`YEAR`、生息地`HABITAT`を元著者の定義で扱う。
- 独立の欧州EIVE1.0温度指標 `EIVEres-T`、幅`EIVEres-T.nw3`、温度指標供給体系`EIVEres-T.n`。元ファイル Zenodo `10.5281/zenodo.7534792` SM08 MD5 `0f0ce19cd2a781eeed027d8b0acadbcb`。完全二名法の学名のみで結合し、異名の推定・属レベルの温度補完なし。

## 事前に固定する比較範囲
1. **線路基質の候補はv340で分類済みの84区画**（うち`railway_track_yard_or_structure`61、`railway_embankment_ditch_or_cut`23、合計13元文献REFERENCE）。これはあくまで`HABITAT`が直接鉄道に関係すると記録された区画。元の橋の垂直壁など、本来バラストと異なるマイクロハビタットは区分して表示する。駅敷地・鉄道から200m離れた土壌など、単なる近隣記述を確証的な線路区画にしない。
2. **対照候補は`HABITAT`にも`LOCALITY`にも鉄道キーワードがない元区画**。ただし「記載がないこと」は真の鉄道非影響を保証しないため、`putative nearby unlabelled reference vegetation`と呼び、**真の独立非鉄道・無作為化対照とは呼ばない**。
3. 主探索ゲートはv340事前固定の**G2同一文献REFERENCE・近傍2km以内・調査年±7年・元調査面積比4倍以内・元位置精度<=1000m**。v340で84鉄道候補中41区画が少なくとも1対照候補あり、対応元文献は5出典。探索的検討に使うが、正確な局所環境・調査努力が同一だという証明ではない。
4. 強い反証ゲート**G1同一出典・500m以内・年±3・面積比2以内・位置精度100m以内**は2鉄道候補・1文献しかないため、ここは推定が成立するかも含める。G4異文献許容2km/±7/4倍/1000mは交絡の大きさを見せる感度、主証拠に昇格させない。
5. 各元文献ごとに、実際の野外地点から**鉄道候補と対照候補を1対1で重複なく割り当て**、結果値ではなく大圏距離、調査年差、面積比だけで最小コスト最大マッチ数を求める（それぞれ `distance_km + 0.1*year_gap + 0.25*|ln(area_ratio)|`）。別の鉄道区画に同じ対照を再利用しない。元種組成・EIVE温度選好・source coverはマッチに絶対に使用しない。
6. 元species tableで`PLANT_GROUP=vascular`、各区画ごとに学名重複を統合（出現種は1回、coverは元`COVER_PERC`の数値最大を採用）。原source`COVER_PERC`は元著者が各元被度階級を標準化した**被度%の推定値**であって個体数・バイオマスでない。元正数値のみを重みとし、空欄/不明/異常値を0にしない。元種×区画に定着・繁殖の実測情報は無い。
7. 研究上の主アウトカムは生息地ごとの群集EIVE温度中心値`EIVEres-T`。元供給指標**3体系以上**、各群集の形質既知種**5種以上、全維管束植物の観測分類群の50%以上**というパネルを第一とする。元EIVE供給1体系以上、各群集3種/30%以上を補助感度、温度幅`nw3`と推定COVER_PERC加重CWMも併記する。被度でのCWMは同じ形質既知種だけを使い、被度欠測の分母と観測EIVE被覆率を別報告。
8. 元出典内で各対応点の鉄道−参照CWMを平均、その後**元REFERENCEを等重み**にする。元studyの実数、比較対数、元地理距離、面積比、調査年差、学名・指標被覆率、効果の方向、出典の外れ値を監査。4本以上の独立元出典で実解析が成立しなければ、メタ解析・広域的普遍性・生態的選別の確証とは呼ばない。
9. 仮に正の差が見えても、駅・橋・盛土・切土の基質／攪乱の違い、群集の開放性、管理、時間、年代、標本採取者、元温度の実測値が未統制。地理的に近いというだけで「鉄道が冷涼地の気候限界を解除した」とは言えない。地理・標高・気候の独立勾配が複数なければ、元の**気候オフセット仮説Aは未検定**。
10. 元著者の種×野外区画生データ、GPS、個別LOCALITYをこのリポに再掲載しない。コード・出典ハッシュ・サンプル数・集計効果のみ、引用先DOIとともに保存する。

## 独立性ゲート
CzechVegの117,739区画は**117,739独立研究**を意味しない。元文献REFERENCE、実採集地、野外地点の空間依存と調査年で層化する。鉄道源は多くても13原出典で、主G2のpotential control supportは5出典のみ。この制限を超えて有意な新規マクロ生態原理を主張することを禁止する。
