# 鉄 v16.9：種間の入れ替わりと真の同種形質シフトを分けるCWMの厳密分解

2026-11-15。**純数学的な方法論修正**であり、元の野外植物群集・写真から「種内の遺伝的適応」を観測した結果ではない。原著はSI 89地点・CZ 39駅の鉄道植生だが、同一季節・同一面積の独立非鉄道植物群集と同種形質値はまだ完備していない。

## 二成分式の解釈を改善する必要

鉄道Rと非鉄道の地理・観測努力が対応した対照Cで、種iの相対的真の個体数/被度を p_iR, p_iC、現地で同種を測った形質平均を z_iR, z_iC、独立外部形質DBの参照値を z_i* とする。

従来の厳密な会計：

ΔCWM = Σ_i (p_iR−p_iC) z_i* + Σ_i[p_iR(z_iR−z_i*)−p_iC(z_iC−z_i*)]

第一項は参照形質値を使う種構成変化。第二項はreferenceからの形質偏差の集約だが、**両環境で同種が観測されなかった植物の偏差も含む**ので、全てを同じ種の鉄道表現型シフト（ITV）と呼ぶのは誤り。

## 4成分の厳密な恒等分解

S = 鉄道・対照の両方で実測した同一種の集合、Ronly = 鉄道だけ、Conly = 対照だけで実観測した種の集合。観測がない場所の種内平均値 z は、DBなどから勝手に補完しない。

1. **T：外部参照平均で評価した種組成変化** = Σ_i (p_iR−p_iC) z_i*。不在側の重みpは0。
2. **P：真に共有され、両方で実測した種の表現型シフト** = Σ_i∈S 0.5(p_iR+p_iC)(z_iR−z_iC)。
3. **I：共通種の構成重み変化×参照からのずれという交互作用** = Σ_i∈S (p_iR−p_iC)[0.5(z_iR+z_iC)−z_i*]。
4. **U：片側にしかいない植物種の参照平均からの偏差（直接のITVではない）** = Σ_i∈Ronly p_iR(z_iR−z_i*) − Σ_i∈Conly p_iC(z_iC−z_i*)。

**ΔCWM = T + P + I + U** が代数的に厳密に成立する。Pのみが元の同種の「両環境における形質差」の直接加重項（それも観測的であって因果ではない）。IとUが従来の広い「種内偏差」に混入しうる。

### 合成値の検算例（生物実測ではない）

鉄道Rに種Aのみ存在し、外部平均形質5、Rでの実平均形質7（p=1）。対照Cに種Bのみ存在し、外部平均形質3、Cの実平均形質2（p=1）。CWM差=7−2=**5**。T=5−3=**2**。旧の「referenceからの偏差」第2項は残余3を出すが、**共通種が0だから同種の形質シフトP=0**。I=0、U=3で、4成分2+0+0+3=5。この3を適応と読んではいけない。

逆に、両生育地に同じ種A/Bが同じ重み0.5で存在し、Aの形質平均が鉄道で対照より+2、Bは変わらなければ、P=0.5×2=**1**、T=I=U=0。この場合、種内の平均形質差が実際に元両生育地で測定されたことになるが、遺伝的適応か可塑性かは依然として不明。
