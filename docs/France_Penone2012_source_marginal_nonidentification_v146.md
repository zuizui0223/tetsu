# v14.6 — 同じ原著種頻度から正負の「路線内−路線間種共有」をどちらも構成できる

**2026-11-15:** Penone 2012 thesis Appendix Bの6種の真正「Number of observations*」を使った**数学的な非識別性の構成的証明**。実際のフランス2路線を35/36地点に分けたわけではない。元の観測数が71地点別の重複なし出現頻度だと仮定した条件付きの解析で、観測単位は依然未確認。

[元の原著6種の出典・注意事項（v14.5）](France_Penone2012_original_thesis_occupancy_v145.md)。

## 何が不明なのかを数学的に確かめる

元の71地点をA35、B36に**仮想的**に分割する。任意の種sの出現地点数f_sは原表値として固定し、Aにa_s、Bにb_s=f_s−a_sを割り当てる。制約は0≤a_s≤35と0≤b_s≤36。地点ごとの種数は不明なので固定しない。

このとき、同グループ地点ペアの**平均共有種数**から別グループ地点ペアの平均共有種数を引いた差Dは、

D = [sum_s (C(a_s,2)+C(b_s,2))] / [C(35,2)+C(36,2)] − [sum_s a_s b_s]/(35×36).

種ごとの取りうる整数a_sを全列挙し、加法的なDの最小・最大を厳密に計算できる。これらは推定された効果量でも信頼区間でもなく、**同じ周辺種数で作成可能な対照的な地点配置の範囲**。

**6種の実出現回数（69,53,39,39,17,3）を保持しても、仮想的グループの平均共有種数差は**

- 最小 **−0.025533 種/地点ペア**
- 最大 **+1.117551 種/地点ペア**

という**符号が逆**の配置を作れる。両極端の証人となる71地点×6種の**合成**presence matrixをコード中で実際に構成し、各種の元の頻度が一致し、数値結果も同じことをテストした。

同時に元の6種から導いた**全地点ペア平均共有種数2.150905は両配置で完全に同一**である。周辺頻度だけでは同グループ・別グループの相違の**符号さえ識別できない**、という厳密な実例である。

## 厳格な境界

A/B=35/36は単なる数学的な区分。原著実際のフランス鉄道路線、同一区間、駅、跨線橋、都市化、調査地点GPS、列車運行方向のいずれでもない。原著Appendix B観測数がサイト別頻度である保証もまだ得ていない。したがってこれは、鉄道散布効果の区間推定・遺伝的適応・外部メタ解析・地理調整済みJaccardでは**ない**。また全群集ではなく6種だけの共有**数**を対象にした識別性の例であり、平均Jaccardの極値ではない。

**生態学的な意義：** 近い路線で共通種が多いという事実だけから移動を仮定すると、地理距離、種プール、観測機会の交絡を散布と誤認しうる。原著71地点×種の元行列＋GPS＋路線中断位置＋環境層を入手して初めて、スロベニアv14.2と同じ帰無検定を適用できる。
