## 同じv332対応ペアを凍結して比較
1. 元対象値：(駅間Track−駅間Interior Plot2)−(近接駅Track−近接駅Interior Plot2)、1対1地理的・標高対応を**元種の温度指標を見る前に固定したv332 G1(15km・75m)**で再現。
2. 探索的パネル：2014年 `strict(EIVE>=3体系、両区5種/50%)×G1`、2014年 `relaxed(EIVE>=1体系、3種/30%)×G1`、同 `relaxed×G2(8km/30m)`、同 `relaxed×G3(種数/被覆率追加)`、2014年 `sparse(EIVE>=3体系、1種以上)×G1`、2017年 `sparse×G1`。これ以外のパネルを良い結果だから主張することはしない。
3. 元の空間sites・zone/yearの**各分類群の存在/不在を完全に固定**し、温度形質だけを全source比較種の間で1999回置換する。元の１種が複数地点に出現しても、1回の置換内では同じ形質値を使う。局所種プールの存在関係、群集種数、駅・駅間、地理距離、路線階層は固定。全種間形質シャッフルは系統・属の温度指標依存性を破壊するため**補助帰無**とする。
4. 原著二名法の**同属内**でのみ数値形質を交換する第二帰無を同じ1999回で実施。移動可能な種・属数を必ず出す。少ない場合、非有意を機構不存在と解釈しない。
5. 各元分類群を**1種ずつ除外**し、v332の一対一駅間/駅の対応を変更せずに全区画CWMを再計算。最小・最大の平均効果、方向が変わる除外件数、削除後も有効なペア数、結果に寄与する上位最大5の学名と効果変化を報告。事後に見つけた種は確証的指標種ではない。
