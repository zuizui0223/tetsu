## 決定的な追加入力欠如：同じ微環境の構内と盛土をペア化できない

同じ原一文献の実EIVE plotで、元鉄道側のyard vs embankmentそのものを**直線距離<=2km、標高差<=50m**で一対一の地理マッチを試みた。しかし**主23組・緩い26組とも両微生育地間の適合ペアは0**。これは「構内と盛土の環境条件を同じ地区で揃えた比較」へ進めなかったことを意味する。原文献は同じだが、源地点・標高・地域種プール・土地被覆・管理履歴・地質が異なりうる。区分に正負の傾向が残ることを、**基質温度・除草・列車風や現役鉄道の作用という機構の確証には絶対に格上げしない**。

**重要な独立性の制限**：これは研究横断4出典による普遍性検定でも1出典内の割付実験でもない。元参考は`HABITAT`と`LOCALITY`に鉄道記述が無い周辺植生であり、真の非鉄道・無影響対照と確認したものではない。`railway_track_yard_or_structure`にはバラスト以外の鉄道橋壁等も含む。CzechVegの推定%Coverは元測定階級からの標準化である可能性があり、バイオマスではない。

## 現時点の判断と次段ゲート

1. **新しいsource backed 記述結果**：元同一文献内でも温度ニッチ中心rail−nearbyは、構内・鉄道構造物候補で正、盛土・切土候補で負。EIVE厳格・緩いパネルおよび出現種/推定被度重みでも**方向自体は一致**。
2. **未証明**：区分の差が鉄道の人工基質による選択圧であるかどうか。同じ文献を使っただけでは、0組の地理的重なりを越えられない。あくまでsource参考区画・微生息地・出典設計の交絡が大きい。
3. **これ以上同一源の恣意的下位群探索だけで肯定結果を増やさない**。最優先は別の**同じ地理/年/面積/管理条件**で railway-structure vs railway-embankment vs nonrail reference を同時採録したデータ取得。チェコ2026年のrailway-yard/embankment/field margin/arable comparisonとポーランド廃線25対草地等の原個票は著者へのリクエストが必要。取得前にフィット済みと報告しない。
4. 元の跨地域温度オフセット仮説A（より寒い地域ほど鉄道と**真の非鉄道**の温度選好差が大きい）は依然未識別であり、上の結果はその支持／反証の確証ではない。
