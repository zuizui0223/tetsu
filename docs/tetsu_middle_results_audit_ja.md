# 全結果監査：v18.0–v28.4と2026-11-17広域検証

監査日：2026-11-20。対象は下記55文書の結果表・結論・制約記載。既存の原資料照合済み解析について文書間の比較対象・更新関係を再確認した。今回は原生態データの再解析・CIの新規再実行をしていない。版番号・感度解析・帰無反復は独立研究として加算しない。既存文書にある「SOURCE SUCCESS」は過去の出所確認記録であり、本監査による新しい再現実行ではない。

## この範囲を一本の問いにする

**同じ人工回廊でも、何が場所を越えて再現し、何が局所の植物相・観測単位・参照の選び方に依存するのか。** 鉄道での特定形質の偏り、現地内の種共有、離れた駅同士の類似、年を越えた再記録、他国への予測は別の応答である。肯定結果をすべて「均質化」にまとめると、このリポで実際に明らかになった相違が失われる。

主要な肯定系列は、局所の種交代と局所的な種共有超過、種固有の微生息地予測、初期の量的順位による再記録予測、条件付き帰無を超える群集機能重心の地点差である。交通量や同一路線の遠隔種共有へ進むほど、信号は縮小または仕様依存になる。これは万能な鉄道効果の不発だけでなく、**局所と遠隔、組成と予測、内部帰無と外部対照を分けて初めて見える構造**として提示できる。ただしこれらを一つの因果過程として実証したわけではない。

## 論文へまとめる構成案

一論文に全25系列の細かな数値を横並びにするより、本文を「局所構造」「遠隔共有」「地域外予測」の3つの問いにして、全結果を証拠地図と補足台帳へ残す。これは肯定だけの選抜ではなく、問いごとに支持と最も強い反証を同じ図に置く構成である。

1. **局所構造**：回廊は隣接群集の単なる縮小集合ではなく、置換が大きい一方で同地点の植物相との結合が残る（M14–16）。多地点間の機能差、annual増加と分散・均質化の非同一性を接続（M07、M09–10、後続v285–303）。
2. **遠隔共有**：同路線・貨物量・国を越えた共通種という強い説明には、地理・頻度・標本粒度・国内対照の厳格化で安定しないものが多い（M11–12、M19–21）。既存文献の貨物散布・連結性の実証を否定せず、このデータでの推定対象の違いを説明する。
3. **予測可能性**：初期量的順位の再記録と種固有の微生息地履歴には移せる情報がある（M08、M17–18）。ただしCzechVeg機能予測のラベル問題と他国鉄道順位の対照依存を併記（M01–03、M20）。予測成功を鉄道固有機構に読み替えない。
4. **同じ現象を比較する条件**：外部参照と内部帰無、同面積・同生息地、種数、形質被覆、過去年を保つ再訪、未知地域の校正条件を明示（M04–06、M13、M22、後続v299–303）。M24–25はデータの限界と次の研究条件に置く。

この構成は原研究の地理・採集方法が異なるため、統一した一つのメタ効果を出すことを前提にしない。全結果の採否・位置づけは以下の出典台帳と親統合文書から追跡する。先行文献との差別化は、既知の外来種増加・生活形選別・貨物散布を新発見として扱うことではなく、**同じ測定軸・対照・予測対象をそろえたときにどの主張が残るかを比較すること**に置く。
