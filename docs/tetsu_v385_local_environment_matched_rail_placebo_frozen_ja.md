# v385 全球の鉄道予測情報の局所環境マッチ反証（新規結果の算出前に固定）
v382/v384bで100km隣接景観Jaccardは道路調整後の予測誤差改善+2.394%/+1.502% (land>=50/80%)、200km負。これは符号のない予測改善なので均質化を直接示さない。v375の広域層内シャッフルより厳しい技術的反証を行う。v382の全4パネル（100/200km、land>=50/80%）を元の植物・鉄道・気候・GHSL・GRIP4・EarthEnv成果物から完全再現（nと元ΔMSEの1e-9一致）。元セルと隣接ペアは固定。
大陸×1000km空間ブロック内の近い環境のセルを重複なしでペアにする。8共変量（BIO1、絶対緯度、log道路密度、GHSL、樹木全セル率、陸地率、log観測数、log観測者数）を各大陸内SDで尺度化。すべての共変量差<=0.75 SDの候補に限定し、距離二乗和最小から決定論的greedy matching。鉄道露出・植物種数・群集類似度・帰化割合をマッチに使用しない。ペアの元鉄道延長を独立確率1/2で交換、未対応セルはそのまま。99回。元と同じ道路調整モデル、大陸holdout、固定ridgeで比較し、隣接ペアの鉄道特徴は交換後の両端点から再計算。実移動可能セル割合<20%またはマッチブロック<20なら技術的順位は算出しない。対応・異なる鉄道値・実交換セル数を開示。技術的placebo順位は地理的交換可能性が保証されたp値ではない。実鉄道地図の空間自己相関を完全には保持しない。既知結果への事後反証であり独立検証でない。
追加として道路調整後の実データ上のlog平均鉄道長、鉄道長差とJaccardの記述的方向を別々に算出（大陸内demean重み回帰）。予測増分と関連の符号を混同しない。元の時点差、観測バイアス、人口・アクセス・気候等の残存交絡を考慮し、鉄道輸送機構、線路内植生、局所侵入や因果的均質化の証拠とはしない。v383帰化種本解析には手を加えない。
