## 実測結果の同一サイト条件

各元植物地理地域で、本物のRAIL文脈plotを1つ選び、同じ地域・元年代・元面積帯かつ**別原著研究**の未交通文脈plotからTH/TFアナログ・非TH/TF・全背景を選ぶ。学名の植物群集とPladias生活形・散布戦略の距離を**同一の実plot組み合わせ**で計算。形質既知5分類群以上、既知割合50%以上をplotの最低条件とした。500反復は原観測内のサンプリング技術反復に過ぎず、現地反復の数や正式なp値・95%信頼区間ではない。

元plot形質未知が多いサンプルは除外。散布戦略だけの参照群で7地域47鉄道plot、両形質既知の参照群で7地域46 plot。原全ソースで同じ元サイト集合を用いた結果からは、生活形既知群および散布戦略既知群ではRAIL−アナログの符号が地域を1つ除いても7/7負。しかし技術的サンプリング分布での主RAIL−アナログ生活形の中央95%範囲は[−0.333246,−0.024665]、散布戦略は[−0.424006,−0.128996]。種数一致28plot/6地域では生活形[−0.177774,+0.043594]、散布戦略[−0.225278,+0.007734]と0を含む。つまり**形質では方向は維持するが、観測支持域制限と生態要因の未識別は解決していない**。

## 生態学上の厳密な解釈

1. TH/TF植生クラスは元植生の学名・優占に基づく群集分類であり、独立環境ではない。**同じ植物組成クラスを対照に選ぶこと自体が種組成・生活形・散布戦略の類似性を高くする**可能性があるため、RAIL−アナログの負の値を『鉄道が自然基質より環境フィルターで均質化しない』との直接結果として扱わない。これは特にこの比較の中心限界。
2. 同じ全国CzechVegの異なるplotと独立原著研究を使うが、原著研究の間で面積・調査季節・観測法が完全等質ではない。元HABITAT/LOCALITYのRAIL語は現役線路敷地・バラストの真の位置を保証せず、元非交通語が無いことは自然生息地を意味しない。
3. Sádloの散布戦略は潜在的な多モード散布形質であり、実際の鉄道車両での種子輸送、到着・発芽・定着を示すものではない。Raunkiaer therophyteは多年草化率などの厳密な生活史ではない。プールは新しい独立の『全球生息地実験』の生物学的反復ではない。
4. クロアチア・ボスニア2017およびイタリア2020の駅内固定マージン生活形帰無とは**別の効果量**。統計的メタ解析で無造作に一つの効果量へ合併しない。
5. Pladiasを相当量用いた投稿前には規約に従いGoverning Boardとの利用・共著可能性を確認し、原著研究者を適切に引用する。
