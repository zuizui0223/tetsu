# 鉄 v17.0：チェコ原著Echium 29組の真正iNaturalist実写真をライセンス確認してブラインド化する

2026-11-15。前段の[真正v16.8](Czech_original_flower_photo_same_month_local_control_v167_v168_ja.md)では、元2020–22年チェコ鉄道駅植物種出現表に含まれていた *Echium vulgare* について、公開iNaturalist 2018–25年写真と元チェコ2023年Geofabrik線路ポリラインを結び、**同種・同年・同月、10km以内、異なる撮影者の29組の観察記録**を1対1に対応できた。これは**画像の中身を29組見て形質判定したという意味ではない**。

今回は実iNaturalist画像を取得し、元々の29組を完全再現した後、**実際に公開レビュー素材へ載せられる両側ともCC0またはCC BYの写真、かつ出典表示のある写真**に限る。元v16.8の「CCライセンスあり」はCC BY-NC/CC BY-SAなども含んでいたので、画像転載という異なる用途に移る段階で絞り込む。**最終的に本物のピクセルを取得・デコードできるペア数は29以下になる可能性がある**。

双方は*Echium vulgare*として**外見上は矛盾しないが、標本的な種再同定ではない**。画像が開いた花を2枚とも含むという目視所見は、元任意のFlowers注釈から推定したのではない。ただしAは花序を大きく写し、Bは広い地表画角なので**見かけの花表示面積・草姿・サイズは撮影距離/向きの差で強く変わる**。元の現場露出・管理履歴・植物の真正鉄道敷地内立地や実際の開花開始日を写真から確定できない。

**この1組には全株サイズ・形態の信頼できる同視野比較対象はゼロ**。開花可視画像の写真1枚×2から、「線路近くほど花が早く咲いた」や「鉄道集団は小型化した」という種内効果量を計算することはできない。この判断はAIアシスタントによる1回の縮小画像の**暫定レビュー**であり、独立2名の研究者によるブラインド再判定も形質ROIの人手元マスクも未実施。

v17.0は事前の実29観察ペアを**先に固定**して、そのまま各両側のCC0/CC BYでの再配布を判定した。画像レビュー効率を上げるため、[v17.1別コホートのソースコード](../scripts/reselect_Echium_CC0BY_before_photo_pairing_v171.py)は、元4,235 iNaturalist観察のうち**CC0/CC BYで両側の利用権がある画像観察を先に選び、その後に同年同月・10km以内・異なる撮影者で再マッチング**する。これは元29組のうち他の組が突然CC BYになる操作ではなく、**元とは異なる写真の組み替えを許す探索的な画像可用性検証**である。真のペア数はそのワークフロー成功後に別途記載する。

## 実写真の取り扱いと視覚的レビュー

1. CC0・CC BYの真正iNaturalist静止画像URL（HTTPSで許可されたinaturalistドメインに限定）だけから画像を実ダウンロード。画像のHTTP状態・最大5MB・JPEG/画像デコード・元ピクセル数・SHAを検査。
2. 両側が許可画像として確認できたペアだけを、**元植物の場所がどちらか伏せたA/B並列画像**にする。画像の表示では距離区分や元の「Flowers」注釈を伏せる。A/Bの左右順は元観察IDのハッシュで決まり、画像内容や効果方向で調整しない。
3. 各画像に必須の著者attribution、原画像への公開リンク、CC0/CC BYライセンス、画像サイズ・生ファイルハッシュを別のimage_attribution_and_verified_bytes.csvに保存。実画像とあわせてGitHub Actionsの**アーティファクト**に入れる。ソースリポのGit追跡コミットには**元画像・正確な座標・元観察ID**を保存しない。
4. フォームblinded_image_human_QA_BLANK_template.csvの植物種同定、開花花が目視で分かるか、完全個体と基部・先端が見えるか、スケールがあるか、道床・線路が写真に見えるかの判定欄は**全て空欄**。**人手の写真判読をしていないなら、yes/noを勝手に埋めない。**
5. 人手判定を固定した後に、UNBLIND_AFTER_human_QA.csvを開き、A/Bの真の線路近接・対照を確認する。「写真に線路が見えないこと」は「線路近接に生えていないこと」の確証ではない。

## 生態学的推定がまだできない理由

- **写真をダウンロードしたという事実は、実際に見える花や草丈を計測したという意味ではない。** 撮影者の距離・倍率・正面/斜め角度・前景の茂み・花序だけを撮った拡大写真は、絶対的な本物の草丈測定に使えない。
- 元「Flowers」注釈は観察者の任意入力で、無記入を**非開花**という真の生理状態に置換しない。単なる撮影日も初花日ではない。
- 線路30mという真のGIS幾何距離でも駅花壇・線路沿い道路・庭園が混入しうる。撮影者と時期をそろえた写真ペアは無作為の草刈り/強風曝露対照ではなく、実際の鉄道敷地内植生の同定でもない。
- 真の種間構成差と種内応答を結ぶ際は[4成分の厳密CWM計算](Rail_CWM_turnover_true_paired_ITV_interaction_unpaired_v169_ja.md)を使い、**同じ種が鉄道/対照の両方で測られた形質差だけ**を直接種内変化と呼ぶ。片側だけに出た種の参照偏差を、遺伝的適応や種内可塑性と取り違えない。
