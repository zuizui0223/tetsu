# tetsu v19.7：肯定結果の階層的統合と検証ゲート（2026-11-16）

この文書は研究ブランチの原本照合済み結果を整理した**内部研究メモ**であり、論文本文・多研究のメタ解析・有意な因果効果の主張ではない。全て先行研究原本の二次解析。作者による新規現地実測ではない。

## 1. 鉄道の効果を「到着・成立・種の組成」に分ける

仮説：各地点での植物出現は、おおまかに **地域種プール（供給可能性）×散布・到着×局所定着・生残×調査検出** という別々のフィルターで決まる。鉄道自体を均一な生息地とみなすのではなく、移動貨物の供給と道床・法尻の環境選別を別の予測として扱う。

* **直接到着（ただし種子の定着ではない）**：カナダBanff・Yohoの原著2017は134 kmの貨物線19地点で貨物由来の穀粒を実捕集（1,979点の採集器サンプルは1,979独立地点ではない）。温暖期2013–15の134 km区間の年間推定は46.0、35.6、112.8 t、冬季は44.6 t。約110 t/年は著者のモデル外挿であり、実際の発芽可能種子量でない。[v13.0原著監査](Canada_direct_freight_train_grain_deposition_v130.md)。
* **貨物界面での野生化**：スイス2011–12の原著79鉄道関連エリア中4箇所でCP4遺伝子型を確認。Basel港・旧貨物駅の交絡がある。原著2013年の分子結果と2013–20の公的監視は同じ地域・経路を追ったので独立した3研究の因果再現ではない。[v13.1–v13.3](Swiss_rail_freight_GM_feral_transition_2011_2020_v131_v133.md)。
* **局所的な微生育地フィルター**：スロベニア89地点/15路線区間の肩BS対法尻BTで生活史・散布戦略の組成差。共通の生活史を調整した厳格風散布群BS−BTは−0.040424、15区間クラスタ再標本化区間[−0.073793,−0.008518]。[v10.6](Slovenia_rail_annual_mix_vs_within_lifespan_wind_v106.md)。
* **種頻度に依存する解釈**：同じスロベニア261種で風散布のBS選好は種均等重み +0.189388、原観測地点での出現機会数重み −0.098125。どちらも真の個体数・種子量重みでない。同じ原著の相反するestimandを「独立の肯定/否定」と数えない。[v11.0](Slovenia_species_frequency_weighting_reversal_v109_v110.md)。
* **未使用路線への予測**：同じスロベニア原著を用いた15路線区間leave-one-outで、生活史×散布ギルドモデルM1の元3状態の平均log-loss 1.085589に対し種固有過去出現履歴追加M2 1.034623（M1比4.695%改善、14/15区間）。これは一般形質群だけでは説明しきれない**種同一性に連動する観測予測**であり、遺伝的な適応・固有の未測定形質を実測したのではない。[v17.2](Slovenia_original_species_vs_guild_15route_microhabitat_predict_v172_ja.md)。

## 2. CzechVeg-Open × Preslia：肯定候補と選択バイアス

独立の2024年Preslia元39駅/761分類群（39駅で*Echium vulgare*を実際に観測）とCzechVeg-Open2026原著117,739調査区×2,510,340植物行。後者の同原著出版研究×植物地理区×年代帯×plot面積帯で、RAIL文脈229区 vs ROAD文脈462区、44ブロック/36元出版研究。*Echium*はRAIL−ROADの植物出現率標準化差 **+6.909 pp**、元36研究1つずつ除外しても最小 **+4.558 pp**。ただし39駅全体植物相とCzechVeg小調査区は異なる粒度。36/36 LOOは独立36実験でなく、候補を元全データで選んだ事後検証。鉄道敷地や列車運転の確認は原HABITAT/LOCALITY文脈では不可能。[v17.4–17.5](CzechVeg_original_39station_rail_context_to_all_Echium_photo_annotations_v174_v175_ja.md)。

**v19.7の新しい否定可能な検査：** 36の原著研究を植物出現率を見る前に原試験の機会数のみで4つに分割。各回3/4の研究で支持基準を満たす正の候補上位20種と負の候補20種を別々に選び、伏せた1/4の研究にのみ予測。元*Echium*等4分類群は過去の全データで発見された探索的候補なので、検証折から数値を隠しても「独立した未見研究」と言い換えない。

元source実行コード：[v19.7](../scripts/validate_CzechVeg_publication_holdout_rail_species_v197.py)。[source-only workflow](../.github/workflows/CzechVeg-source-publication-holdout-v197.yml)。足りない検証群は**ゼロ/負**でなく**測定不能**。出版研究ごと分割でも地域/研究者/管理履歴が完全に交換可能になるわけではない。p値や独立なメタ解析のサンプルサイズは算出しない。

## 3. 鉄道は地域フロラを「上書き」するのか

* クロアチア13駅＋ボスニア2駅という**1原著**：359分類群、15駅。気候群内で駅別種数・種別出現駅頻度を固定した原著内部の帰無で、分類群Jaccardの観測−帰無 = **−0.0007792**、5生活形重複 = **−0.0259514**。帰無を超える鉄道群集の分類学的収束は未支持。[v18.5](rail_flora_taxonomic_vs_functional_fixedmargin_v185_ja.md)。
* イタリアParma 28駅×438分類群の**別の1原著**：plain/other別の固定マージン帰無では分類群Jaccard観測−帰無 **+0.0015740**、6生活形重複 **−0.0124970**。2原著での機能重複の負符号は再現するが、鉄道vs自然植生の地域種プール比較ではない。[v18.8と原出版表の独立照合](Parma_2020_original_28station_source_functional_joint_v186_v188_ja.md)。
* CzechVeg v19.6：同じ原RAIL候補37区/4植物地理区を固定し、参照だけを変更。植物組成定義のTH/TF/TGアナログ参照では交差地域種Jaccard差RAIL−参照=**−0.0331516**、原標高±100mの参照では**+0.0008336**。種数条件を加え21区でも−0.0261536と−0.0029120。全て技術標本区間はゼロを含む。植物相自体を使ったSYNTAXONカテゴリで自然参照を選ぶと自己選択が起こる。[v19.6元原本MD5照合済み](CzechVeg_same_site_abiotic_vs_syntaxon_reference_v196_ja.md)。

## 4. 論文化の主張の強さと停止規則

|主張|現時点|続行に必要な独立ゲート|
|---|---|---|
|実際の貨物列車が穀粒を落とす|原著で直接観測|野生植物種の発芽可能種子到着と区別|
|道床肩と法尻の形質・種差が再現する|スロベニア単一原著で強い観測予測|別原著・別国の比較可能な微生育地×種行列|
|特定植物がRAIL文脈に多い|チェコの正の探索的指標|v19.7未使用出版研究での符号・支持率検査、さらに実敷地vs道路確認|
|鉄道生息地が地域フロラを全球で均質化する|未識別|非rail同じ粒度の独立地域種プール、外部物理基質/管理/地理、生息地確認|
|貨物運搬が野生植物相の均質化を引き起こす|未検証|到着→定着のリンク、道路/人為物流・土地利用の対照|
|遺伝的適応で鉄道植物が形質変化|未検証|同種比較の測定形質と遺伝的/共通環境証拠|

### 直近の判定優先順位

1. **新規v19.7が最優先**：独立原著研究ごとのtrain/heldout符号を結果選択なしで全部報告し、検証折の支持不足を数える。Echiumが弱まれば、肯定主張を「全元研究で選択された候補」へ下げる。
2. **次の主要仮説は地域種プール×微生育地**：SYNTAXON群を比較参照に使わず、外部で測られた基質・傾斜・土壌・日照・管理が定義する天然対照から、生物地理的類似度の増加を推定する。
3. **種内形質と散布機構は別論文線**：現在の公開写真から開花「なし」を作らない。鉄道を経由した到着と遺伝的適応を混同しない。

**出版研究n**は各同一原著の駅数・調査区数・テクニカルブートストラップ数とは異なる。前向きな新規外部データがない限り、全体のp値は合成しない。現行研究は[Draft PR #1](https://github.com/zuizui0223/tetsu/pull/1)に保持し、mainへ未統合。
