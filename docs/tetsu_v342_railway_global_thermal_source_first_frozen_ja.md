# v342 source-first feasibility protocol: independent thermal affinity and true railway comparators (2026-11-24)

## Primary ecological estimand, frozen before fresh GBIF/Australian observations
For each original same-site, same-area railway Track and **local non-rail reference** (or explicitly railway-adjacent interior if no independent natural comparison), define
`Delta_T = CWM(T_species | rail) - CWM(T_species | reference)`.
Estimate region-specific `Delta_T`, not sample-count weighted cross-country pooled mean. A claimed region-general railway effect needs >=2 geographically independent railway field programmes **with genuinely comparable local paired controls**, and matched trait calibration. Single Kashmir corridor is a case study, not global replication. Publication-specific plots and sources remain independent in data structure even if data are homogeneous.

## Mandatory source-gate sequence (no exploratory result shopping)
1. **Australia Everingham 2019 (DOI 10.1111/aec.12719)**. Try publisher's explicitly linked `aec12719-sup-0002-AppendixS4.xlsx` from article Supporting Information using exact canonical onlinelibrary URL(s), validate HTTP status, file magic XLSX (ZIP), original worksheet names and first-row schema. Record only aggregate sheet dimensions/headings, source sha256 when accessible; no original species/plot matrix or GPS mirrored. `Everingham` includes railway embankments/fire trails/roadside, but the paper calls it a *complementary sclerophyll forest disturbance-gradient survey*, **not a guaranteed within-locality matched railway/forest pair**. Unless fields identify identical matched source location, plot area/date and sampling protocol, do not use as strict matched rail-vs-nonrail.
2. **GBIF v1 API** `occurrence/search` and `species/match`. Verify small prespecified anchor species `Cynodon dactylon`, `Poa annua` for counts, accepted exact taxon identity and sample record fields. This is **only connectivity and taxon-resolution gate**, not a defensible world climatic niche, because GBIF search is limited to 300/page and the 100,000 offset+limit cap. GBIF bulk download needs authenticated asynchronous request and DOI for full global inference. Do not call first 300 records a global distribution or claim the presence-only mean is an ecological optimum.
3. **WorldClim v2.1** `wc2.1_10m_bio.zip` = reference bio1 and other bioclimatic rasters from the explicit official geodata.ucdavis.edu hostname. Verify TIFF named `wc2.1_10m_bio_1.tif` and report file hash, archive count and raster metadata only; do not invent climate values or site temperatures. WC21 historical means refer to 1970–2000.
4. **Data-use considerations**: GBIF records have geographic bias, invasive/native-range mixing, taxonomic synonym risk, coordinate error, accessibility clustering, and spatial thinning; WorldClim grid cell climate is not ballast microclimate. Event times/habitat metadata must not be inferred from GBIF presence points. For a formal species climatological niche, use reproducible GBIF DOI download, occurrence-status PRESENT, coordinate + geospatial-issue filters, 1970–2000 or explicitly season/time-aligned records, optional coordinate uncertainty <= 5km and no missing, exclusion of inaccessible/cultivated/country-centroid GPS, one per equal-area cell / sample target-group correction, country/continent and native-range sensitivity, >=30 independent cells species, explicit distribution and coverage.
5. **Cross-trait validation**: first validate GBIF-WorldClim independent species temperature ranks against native-region EIVE (European-calibrated) on shared European taxa **without relying on Kashmir's EIVE result for model tuning**. Need external data and sample coverage; a random 300-GBIF occurrence API pilot is not this validation.
6. **No source access = STOP**: archive a candid false/true source-access table without estimates. If Australia original species data unavailable, or no source-matched railway/local controls, do not manufacture an Australia-versus-Kashmir thermal difference or climate-gradient slope.

## Decision
If true independent local railway/nonrail pairs cannot be source-verified, conclusion is **not identifiable with current open datasets**. Produce a precise permission/data request, or pursue **within-railway thermal filtering** as the observational paper instead. Do not quietly substitute MIREN ROAD as a railway case or Spain topsoil randomized management treatments as railway vs nature.
